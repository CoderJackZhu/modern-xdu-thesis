## 测量方法

使用 `dev/inspect-public-thesis.py` 和PyMuPDF读取文字的 `origin`（基线），
不把文字包围盒底边当基线；读取绘图对象核对横线位置、线宽和线型。
正文按12pt长行筛选，统计相邻基线差及左右边界众数。每份原生PDF从第一章起抽样10个物理页；
章节首页、段首缩进、插图、短行都会影响样本数量，众数不是每个对象都相同的承诺。

```bash
python3 dev/inspect-public-thesis.py <论文.pdf> --chapter-page <第一章物理页> --pages 10
python3 dev/inspect-public-thesis.py <扫描论文.pdf> --chapter-page 17 --scan
```

五份原生PDF第一章物理页依次为：刘艺涵9、吕瑞涛11、刘畅25、薛浩昱27、李瑞远29。
下表单位均为bp（1/72英寸）；LaTeX的20pt换算到PDF约19.93bp，
Typst的20pt为20bp。这个差值不作为行距失效。

## 与当前实现的关系

### 本科

当前实现正文行距23.40bp、奇偶左界113.39 / 56.69bp、页眉基线61.51bp，
与刘艺涵成品的相应值接近（页眉差0.05bp）。吕瑞涛成品的页眉及横线均更低约3bp，
正文行距也不同；不能同时对齐两份历史成品。
章标题位置在两个样本中亦有差异，继续按[本科规格](本科规格.md)及既有55页实物验收尺裁定。

本次修正的是英文摘要标题粗体、示例后置顺序及正文引用约8pt上标，
详见[本科模板对比](本科模板对比.md)。55页压测保留转换后的分页骨架，
不声称将公开54页或69页论文逐页复现。

### 博士前置页

李瑞远成品的封面、中文题名、英文题名和声明分别位于物理p1、p3、p5、p7；
博士学位、学科、导师、作者、学院、日期等字段及 `A dissertation` 文案均能提供成品旁证。
当前博士实现的相同前置顺序及培养层次文字已作自动化检查。

李瑞远2020中文题名页比当前Word锚点实现约高1–3mm，英文题名页标题约低7mm。
因此成品用于结构和主体交叉核对，当前前置页坐标仍按学术Word 2025.01和专业Word 2026.5；
原始文本框锚点、字号、字段和专业博士有/无企业导师的规则见[博士规格](博士规格.md)。
旧学术博士论文无法证明2026专业博士封面合规。

## 验证结论及边界

本科三项修正和博士实现均有PDF测量及故意改坏输出的负向测试。
2026-10-29完整回归为38项通过、0项失败，包含实际执行的官方逐行对照、
硕士112页与本科55页压测、博士Word锚点自检、盲审与包外编译；
默认初始化仍为2个文件、33页。
本地本科官方手册与Word样例缺失，未重新执行这两份外部材料核对；
本科验收尺已在55页实物PDF上自检。

公开成品核对是按上述命令执行的只读抽样，不计入38项自动化汇总。
论文全文未转换成博士压力测试输入，因此不声称已完成158页博士内容的重排或逐页复现。
LibreOffice导出中文字体替换不能作为原生Word像素级金标准；XML锚点核对也不能证明所有字体的墨迹一致。
本地检查没有取得学校的实际格式检测结论，提交前仍应以所属学院当届要求为准。
