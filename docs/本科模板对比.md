## 对照方法

将同机编译的上游默认示例、本项目示例与本科参考论文的 PDF 反向测量结果比较，
并检查 `xduugthesis.cls`。本项目规格和参考论文证据详见
[本科规格](本科规格.md)、[本科验收报告](本科验收报告.md)。
上游 README 面向 Typst 0.13，本次使用本机 0.15.1；结果是这一环境下的默认输出，
不能代替对其所有版本、配置和学院格式检测的判断。

## 默认输出的差异

| 项目 | 上游默认示例 | 本项目 / 对照依据 | 判断 |
|---|---|---|---|
| 双面页边距 | 左40mm、右20mm；`symmetrical-margins` 默认 false | 奇页40/20mm，偶页20/40mm | 上游提供对称开关，双面使用应开启；默认偶页版心比参考向右20mm |
| 正文基线距 | 约25.32pt | 23.40pt，与参考论文和类的基线设定一致 | 保留本项目，不能直接把 `leading` 设成相同磅值 |
| 页眉文字基线 | 距页顶约18.88mm | 本项目21.70mm，参考约21.68mm | 本项目更接近参考 |
| 页面/章标题基线 | 约34–35mm | 本项目约42.8mm，与参考一致 | 保留本项目 |
| 英文摘要标题 | `Abstract` | 类定义为 `ABSTRACT`、16pt TNR粗体 | 本项目大写正确，原来的非粗体需修 |
| 封面 | 主标题、填写线与参考坐标不同 | 本项目依据参考坐标；官方标识由使用者提供 | 不照搬上游；上游README也建议按学院Word制作封面 |
| 后置顺序 | 致谢 → 参考文献 → 附录 | 类定义同此；本项目示例原为附录 → 致谢 → 参考文献 | 本项目示例需修 |
| 正文上标引用 | 有格式检测调整记录 | 本项目原 `0.9em` 经上标缩放仅约7.019pt，参考正文约7.97pt | 本项目改为显式8pt，并同时测手动引用与真实cite |

上游相关定位：`template/template.typ` 的正文与页面设置、`template/utils.typ` 的页眉、
`template/frontmatter.typ` 的英文摘要，以及 `template/cover.typ` 的封面。
比较针对默认配置；可配置选项改变后，输出也会改变。

## 本次采纳与验证

1. 本科示例及 README 改为“致谢 → 参考文献 → 附录”。函数仍允许学院要求的自定义顺序；
   55页转换稿保留其分页骨架，不借机重排既有压力测试内容。
2. 仅英文摘要标题改为16pt TNR粗体，中文页面标题不随之加粗。
3. 正文手动 `引用(...)` 与 `cite` 都固定为合成8pt上标，避免字体 `sups` 或 CSL 内部上标二次缩放。
   参考论文题注等小字号语境存在约6.974pt的引用，本次没有据此修改题注字号。

新增 PDF 检查与负向测试覆盖标题粗体、后置顺序、两类引用字号及上移基线。
上游关注度值得参考，但本项目不需要整体向其默认版式靠拢；
可借鉴的是已有使用反馈及缺陷修正，再以学校材料与 PDF 数值决定是否采纳。
