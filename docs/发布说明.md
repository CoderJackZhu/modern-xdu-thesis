# 0.3.2 发布说明

本次补丁修复长题目、表格、公式、文献、标题复用和输入校验。包名、作者与许可保持不变。
GitHub Release 附过滤后的独立包载荷与 SHA256；Universe 提交、社区合并与实际可下载
分别记录，不能互相替代。

## 本次修正

- 研究生正文表格改为既定的宋体五号 10.5pt，保留 0.5pt 表格线。
- 研究生中英文题目自动折行与显式分行均保持固定 30pt 行距，超出固定区域时中文报错。
- 研究生及本科多行公式编号对齐最后一行；本科 `.bib` 模式按语言区分“等”和 `et al.`。
- 题目、作者、学号的空值、固定单行字段或页眉超宽、题目过高、五级及更深编号标题
  均给出明确中文诊断。本科题目最多两行；这些是模板输入约定，不是学校新增要求。
- 标题复用只重建已知文本容器，向量、分段公式、对齐、旋转、栈和网格保持有效。
- 目录与页眉不再复制标题脚注；覆盖富文本、链接、`context` 和公式内脚注，
  保留样式并保持脚注计数连续。
- 本科、硕士及博士中文作者槽位支持数组连接，保留富文本样式和纯字符串数组元数据；
  研究生盲审继续隐藏身份。
- 本科页眉按当前页码实际宽度预留空间，覆盖奇偶页、罗马页码与多位阿拉伯页码。

## 本次验证

- `bash dev/check-all.sh`：40 项通过、0 项失败。包含硕士 112 页、本科 55 页、
  博士与配套材料、默认初始化恰有 2 个文件且编译 33 页。
- 原九项专项回归及新增四组标题复用/作者数组/页眉回归均已接入总入口，
  其失败会传播到总入口退出码。
- 新增四组回归在原始 `21bb3c4` 隔离副本上全部失败，在修复后全部通过。
- 独立载荷 40 个文件，隐私扫描 0 个禁用引用；包内初始化为 2 个源文件、33 页，
  7 份包外示例全部编译通过；官方 `typst-package-check --offline` 无诊断。
  在线链接检查在版本标签推送后另行执行，结果记录在 GitHub Release 中。

## 本次边界

- 本次缺少官方 `templet.pdf`、本科手册/Word 和博士原始 Word 配置，相关原件对照
  未验证。历史原件验收不等于本次重新通过。
- `context` 内定义带标签的标题脚注仍会报重复标签错误；可在普通内容中定义标签，
  再在 `context` 中引用，示例见 README。
- 字体度量差异导致换行点漂移，不能声称逐行、逐像素复现；附录仍缺官方实测依据。
- 开题/中期原表的 A3 套印、签批及学校系统要求仍需按学院通知复核；
  课程实验报告不是学校统一模板。

## 本次发布步骤

1. 清单、当前示例导入、文档命令与验收包路径同步为 `0.3.2`，运行完整验收。
