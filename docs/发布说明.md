# 0.3.0 发布说明

维护者已确认继续发布新版本，版本号为 `0.3.0`。GitHub Release 附独立包载荷与 SHA256
校验和；Universe 收录需经过独立的社区审核。发布进度分别以
[GitHub Release](https://github.com/CoderJackZhu/modern-xdu-thesis/releases) 和
[Universe 提交记录](https://github.com/typst/packages/pulls?q=is%3Apr+modern-xdu-thesis)
为准。PR 提交、社区合并和实际可下载是三个不同状态。

## 新增

- 研究生开题报告入口 `proposal-documentclass`，覆盖学术/专业硕士、学术/专业博士。
- 研究生中期考核报告入口 `interim-documentclass`，覆盖上述四类研究生。
- 本科开题报告与中期报告入口，依据本科生院《毕业设计表格-全套》第 5、6 号表。
- 通用课程实验报告入口，明确标注为非学校统一模板，教师指定模板优先。
- 配套材料规格、导航和完整示例，记录官方来源、学院差异、A3 套印要求和验证边界。
- `dev/test-supporting.py`：11 类文档的编译、字段、章节、页面、页边距、行距、框线与
  A4 尺寸验收，并注入错误结构、错误页面尺寸和越界墨迹三种失败。

## 修正

- 按原始 Word 表区分硕士与博士专业学位封面：专业硕士为“领域、校内导师、校外导师”，
  专业博士为“领域（方向）、指导教师”；专业博士开题/中期意见页仍保留校内、校外双签。
- 专业博士开题的意见页不再将校外导师签名单独遗落到空白末页。
- 本科中期第 8 节不再只在页尾保留标题、把盖章区拆到下一页。
- 开题、中期和本科中期封面页脚上移，避免宋体字面下缘侵入下页边距。
- 页边距验收改为扫描真实墨迹，区分 CJK 标点字形外框与真正越界。

## 沿用的 0.2.0 内容

- 学术博士与专业博士共用研究生排版系统，支持博士专用封面、中英文题名页、盲审和专业博士
  有/无企业导师。
- 博士正文、填充页、后置部分页眉及作者简介成果栏按培养层次切换。
- 本科后置顺序、英文摘要标题、8pt 合成引用上标修正。

## 验证

完整入口 `bash dev/check-all.sh`：38 项通过、0 项失败。覆盖发布载荷扫描、全部入口编译、
硕士/本科/博士 PDF 测量、开题/中期/课程报告与失败注入、真实长论文压力测试和
`typst init` 分发验收。

默认 `typst init` 仍生成硕士项目，目录只有 2 个源文件，编译结果为 33 页。开题、中期和
课程报告示例从包外导入，证明新增模块进入发布载荷。

## 使用与验证边界

- 开题/中期原表要求 A3 正反套印，本包输出 A4 单页排版稿；系统申请、签字扫描、学院审批
  和最终装订仍以当期通知为准。
- 课程实验报告没有校级统一模板，不能把该入口描述为学校官方模板。
- 科研实验记录本、答辩、评阅、审批和经费表不批量复刻；没有全校统一版式时不凭推测制作。
- 本地自动化验收不等于学校格式检测、学院审批或原生 Word 逐像素一致。

## 发布步骤

1. 将清单、示例导入、文档命令和验收包路径同步为 `0.3.0`，重跑完整验收。

4. 若先前版本 PR 尚未合并，先确认其状态，再向 `typst/packages` 提交 `0.3.0` 目录；
   不修改已经合并的旧版本目录。
5. 分别记录 GitHub 发布、Universe PR、社区合并和实际可下载状态。
