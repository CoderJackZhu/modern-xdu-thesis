# 0.2.0 发布说明

维护者已确认本次版本为 `0.2.0`。GitHub Release 附独立包载荷与 SHA256 校验和；
Universe 收录需经过独立的社区审核。发布进度分别以
[GitHub Release](https://github.com/CoderJackZhu/modern-xdu-thesis/releases/tag/v0.2.0) 和
[Universe 提交记录](https://github.com/typst/packages/pulls?q=is%3Apr+modern-xdu-thesis) 为准。
已收录的旧版 `0.1.0` 不包含本次本科修正与博士支持。

## 新增

- 学术博士与专业博士共用现有研究生排版系统，可从 `doctor-documentclass`、
  `documentclass(graduate: "doctor")` 或本地 `doctor.typ` 进入。
- 博士专用封面、中英文题名页，支持专业博士有/无企业导师、盲审、学位英文名覆盖。
- 博士正文、填充页与后置部分的固定页眉，以及作者简介成果栏按培养层次切换。
- 完整博士示例及配套文献；新增博士PDF测量、官网Word锚点核对与负向测试。

## 修正

- 本科示例后置顺序为“致谢 → 参考文献 → 附录”。
- 本科英文摘要标题为16pt Times New Roman粗体 `ABSTRACT`。
- 本科正文手动引用与 `cite` 使用约8pt合成上标，避免二次缩放。
- 验收总入口按编译/测量真实退出码汇总；显式环境变量优先于本机路径配置，
  避免有效官方PDF路径被覆盖后静默跳过。
- README、写作要求和包描述补充博士支持，文档入口与实际包载荷保持一致。

## 验证

完整入口 `bash dev/check-all.sh`：38项通过、0项失败。实际使用官方PDF、两类博士原始Word，
执行硕士112页和本科55页压力测试、博士组合及失败注入、分发载荷扫描和包外编译。
`typst init` 默认仍生成硕士项目，2个源文件，编译33页。
另对六份公开本科、硕士、博士成品进行只读抽样测量，详见[交叉核对报告](公开成品交叉核对.md)。

## 使用与验证边界

既有硕士和本科入口保持兼容，默认初始化仍为硕士。博士示例需连同
`examples/doctor-ref.bib` 一起复制；专业博士企业导师中英文信息须同时填写或同时省略。
不附带商业字体或学校标识素材。

本科官方手册及Word样例的本机文件缺失，本次未重新核对这两份外部材料。
专业博士尚缺采用2026.5专用前置页的公开成品；当前按官网原始Word锚点核对。
本地验证不等于学校实际格式检测，也不声称原生Word逐像素一致或158页博士全文逐页复现。

## 发布步骤

1. 将清单、示例导入、文档命令和验收包路径同步为 `0.2.0`，重跑验收。
2. 从清单排除规则构建独立载荷；从该载荷再次验证初始化及本科、博士包外编译。
3. 提交并推送源仓库，创建相应Git标签与GitHub Release，附包载荷及校验和。
4. 向 `typst/packages` 的新版本目录提交PR，保留已发布0.1.0目录不变。
5. 分别记录GitHub发布、Universe提交、社区合并和实际可下载状态；PR提交成功不等于已上架。
