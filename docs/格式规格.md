## 2. 硬约束（逐条可验收）

### 2.1 页面

| 项 | 值 |
|---|---|
| 纸张 | A4，210 × 297 mm |
| 装订 | 双面打印（`twoside`） |
| 上 / 下边距 | 30 mm / 26.07 mm（下边界取 270.93mm，见下注） |
| 内侧 / 外侧边距 | 30 mm（2.5 + 0.5 装订线）/ 25 mm |
| 版心 | **155 × 240.93 mm**（起；原为 247mm，已推翻） |
| 页眉距页顶 | 20 mm |
| 页脚距页底 | 17.5 mm |
| 行间距 | 固定值 20 磅（题名页除外） |
| 字符间距 | 标准 |
| 章节起始 | 每章必须从**奇数页**开始（不足补空白页） |

> **每页行数（重新裁定）**：版心 240.93mm ÷ 20 磅（7.056mm）→ **每页最多 34 行**，
> 与两份官方 LaTeX 实现一致（官方 `templet.pdf` 实测每页最多 34 行，最底那行基线 270.89mm）。
>
> **裁决理由（推翻旧的 247mm）**：247mm 会让每页多排一行（35 行而非 34 行），长文档总页数
> 系统性偏少 —— 实测一份 112 页的真实论文在 247mm 下会短 3–5 页。旧值来源于规范文字的
> 「下边距 2cm」，但两份官方 LaTeX 实现都不遵守该值（官方 2024.04 的 `\textheight=24cm`）。
> 项目目标是「符合官方 LaTeX 模板做出来的样子」，故跟随 240mm。详见
> `docs/与真实论文对照.md` §4。
>
> → **验收口径：基线距恒为 20pt；每页最多 34 行（容量，不要求每页排满）。**

#### 字体要求（实测裁定）

**全篇只需要三种字体：宋体 / 黑体 / Times New Roman。**

依据：官方 `templet.pdf` 全 44 页只嵌入 `SimSun`(75) / `NimbusRomNo9L`(77，TNR 开源等价物) / `SimHei`(17) 三种正文字体，**楷体与仿宋 0 次出现**；Word 侧 `styles.xml`、`document.xml` 中同样为 0 次。

**本模板不内置任何字体文件**，按「系统字体优先 + 回退链」解析：

| 平台 | 宋体 | 黑体 | 西文 |
|---|---|---|---|
| Windows | `SimSun` | `SimHei` | `Times New Roman` |
| macOS | `Songti SC` / `STSong` | `Heiti SC` / `STHeiti` | `Times New Roman` |
| Linux | `Noto Serif CJK SC` / `Source Han Serif SC` | `Noto Sans CJK SC` / `Source Han Sans SC` | `Times New Roman` 或 Nimbus Roman |

- 黑体的**西文也用 Times New Roman**（官方输出无 Arial；原 NJU 骨架用的 Arial 已弃用）。
- 字体缺失时 Typst 会落到系统兜底字体（macOS 上可能落到手写体），回退链已按上表补全。
- 编译时出现 `unknown font family: simsun` 等警告属正常——那是回退链里本机没有的候选。
- 仓库自身的字体文件（Monotype Arial/TNR、方正仿宋/楷体）**已移出仓库**：均为商业字体，在 MIT 仓库中再分发有版权风险，且楷体/仿宋/Arial 用不到。这些文件已从仓库移除，不再随仓库分发。

### 2.3 页眉页脚

- 奇偶页不同。
 - 偶数页页眉：`西安电子科技大学硕士学位论文`
 - 奇数页页眉：当前章节名

 - 前置：罗马数字（`I II III…`），Times New Roman，小五

### 2.7 实现约束（实测得出，必须遵守）

以下三条是实现上述格式数值的**唯一可行方式**，换写法会导致版式偏差：

**1. 固定值 20 磅行距**

```typst
#let 基线偏移(行盒, 字号) = (行盒 - 字号) / 2 + 0.88 * 字号  // 字身框在行盒内居中
#let 上伸 = 基线偏移(20pt, 12pt)  // 14.56pt
#let 行隙 = 20pt - 上伸      // 5.44pt
#set text(top-edge: 上伸, bottom-edge: "baseline")
#set par(leading: 行隙, spacing: 行隙)  // spacing 必须显式设，默认 1.2em = 14.4pt 会破坏行网格
```

- Typst 的 `par(leading)` 是行盒间的空隙，不是基线距；`Δ + leading = 20pt` 才得到精确 20pt 基线距。
- `top-edge` 让行盒顶落在正文区顶边，**保证字身框不越出 3cm 上边距**。
- Typst 的 `bottom-edge` **不接受长度参数**（实测被静默忽略），无法把行盒直接做成 20pt。

**2. 章标题段前必须用强间距**

- `block(above:)` 的段前间距在**页顶会被 Typst 折叠**，官方 Word/LaTeX 不折叠。
- 章标题总在新页起，因此必须用显式 `v(24pt)`（强间距）实现段前，段后同法用 `v(18pt)`。
- 章标题与正文**共用同一个 20pt 行盒**（16pt 标题 ⇒ Δ = 16.08pt）。实测复现官方章首页：章标题 125.12bp（官方 125.44）、正文首行 163.12bp（官方 163.29）。
- 节/小节可继续用 `block(above:)`——Typst 的间距折叠恰好给出正确值 `max(段落尾距, 标题段前)`。

**3. 页眉 / 页脚定位**

- **页眉帧顶 = 上边距 − `header-ascent`**；**页脚帧顶 = 版心下边界 + `footer-descent`**（两条规律为实测得出，斜率严格 ±1，与文档字号无关）。
- 前提：页眉/页脚内容必须是**零高度框**且用 `place` 摆放，否则基准漂移。
- 双横线用两个 `place` 的 `line`（各 0.5pt、dy 差 1pt）；用 `v()` 在段落流里排版会得到 5.94pt 而非 1pt。

## 3. 学术学位 vs 专业学位 —— 唯一变量

两份 Word 的**页面参数与样式表逐字节一致**，正文规范完全相同。差异只在封面和题名页。

### 封面

| | 学术学位 | 专业学位 |
|---|---|---|
| 字段 | 题目 / 作者姓名 / 指导教师姓名、职称 / 申请学位类别 | 题目 / 作者姓名 / **学校导师**姓名、职称 / **企业导师**姓名、职称 / 申请学位类别 |

### 中文题名页

| | 学术学位 | 专业学位 |
|---|---|---|
| 固定栏 | 学校代码 10701、分类号、学号、密级 | 同左 |
| 字段 | 作者姓名 / **一级学科** / **二级学科（研究方向）** / 学位类别 / **指导教师姓名、职称** / 学院 / 提交日期 | 作者姓名 / **领域** / 学位类别 / **学校导师姓名、职称** / **企业导师姓名、职称** / 学院 / 提交日期 |

### 英文题名页

| | 学术学位 | 专业学位 |
|---|---|---|
| 导师栏 | `Supervisor: …` ×1 | `Supervisor: …` ×2（学校 / 企业） |

### 结论

**一个选项 `degree: "academic" | "professional"`，只影响封面 + 中文题名页 + 英文题名页这 3 个页面。** 其余全部共用。

## 4. 技术方案

### 4.1 载体

**在现有仓库上改造**（原名为 `XDUthesis-Typst`，发布前已统一更名为 `xdu-master-thesis`，与包名一致），理由：

- MIT 许可，可自由分发
- 已有 `documentclass(doctype, degree, …)` 配置架构，`degree` 开关正好对应学硕/专硕
- 不依赖任何内置字体文件（见 §2.2）

需要清掉的南大残留：

- `pages/` 下所有 `master-*`、`bachelor-*` 页面（是南大版式，含 `学校代码 10284` 等错误字段）
- `lib.typ` 中南大语义的配置项（`nl-cover` 等）
- `layouts/` 与 `utils/` 需按西电规范重写；仅少量通用工具（自定义编号、双语参考文献封装、tablex 封装）可评估后保留

### 4.3 关键技术点（有实现风险，先验证）

| # | 问题 | 方案 | 风险 |
|---|---|---|---|
| 1 | Typst 的 `par(leading)` 是**行间空隙**，不是基线距，无法直接写「固定值 20 磅」 | 用 `text(top-edge: "baseline", bottom-edge: "baseline")` 把行盒压成 0 高，再用 `leading: 20pt` 得到精确基线距 | **高** — 需实测确认不裁字、不影响行内公式与图片 |
| 2 | 页边距内侧 30 / 外侧 25 | `page(margin: (inside: 30mm, outside: 25mm, top: 30mm, bottom: 20mm))` | 低 |
| 3 | 页眉距页顶 20 mm 且下方双横线 | 页眉元素控制高度 + 两条 `line`，左右各外扩 4pt | 中 |
| 4 | 前置罗马 / 正文阿拉伯，各自从 1 开始 | 双计数器 + `counter(page).update(1)` + 自定义 `numbering` | 中 |
| 5 | 每章从奇数页开始 | `pagebreak(to: "odd")` | 低 |
| 6 | 四级标题 `（1）` 且不进目录 | 自定义 heading level 且 `outlined: false` | 低 |
| 7 | 字体跨平台 | 见 §4.4 | **高** |

> **验证结论：7 项全部通过，无一项需要更换方案。** 实测数据见 [docs/版式实现.md](版式实现.md)。
>
> 两条实测得出的 Typst 定位规律（官方文档未述，实现依赖它）：
> - **页眉帧顶 = 上边距 − `header-ascent`**（斜率严格 −1，与文档字号无关）
> - **页脚帧顶 = 版心下边界 + `footer-descent`**
>
> 前提：页眉/页脚内容必须是**零高度框**并用 `place` 摆放，否则基准漂移。

### 4.4 字体策略（必须先定）

官方要求：宋体 / 黑体 / 楷体 / 仿宋 / Times New Roman。

现实约束：**宋体、黑体没有可自由分发的字体**（Windows 的 SimSun/SimHei、macOS 的 Songti SC/Heiti SC 都不可再分发）。仓库现有内置字体只有方正仿宋、方正楷体（商用授权）和 TNR。

三种可选路线，**需你选一个**：

| 方案 | 优点 | 缺点 |
|---|---|---|
| **A. 只声明字体名，让用户自己装**（默认 win/mac 两套映射） | 无版权问题、输出最贴近官方 | 开箱即用性差，Linux/CI 需自行配置 |
| **B. 内置开源替代字体**（思源宋体 / 思源黑体 / 霞鹜文楷等） | 跨平台一致、开箱即用 | 字形与宋体有肉眼差异，格式检测虽不查字体文件但观感不同 |
| **C. A + B 混合**：默认走系统字体，缺失时回退到内置开源字体 | 兼顾 | 实现稍复杂 |

**建议 C。** —— **复核后改为「不内置」**：

实测官方硕士模板全 44 页只嵌入 `SimSun` / `NimbusRomNo9L`（TNR 等价物）/ `SimHei` 三种正文字体，**楷体与仿宋 0 次出现**（Word 侧亦然）。仓库现有 6 个内置字体文件（Monotype ×5、方正 ×2）**全是商业字体**，在 MIT 仓库里再分发有版权风险，且楷体/仿宋用不到、Arial 也用不到。

→ **最终方案：不内置任何字体文件；系统字体优先 + 完整回退链 + README 写明要求。** 详见 §6 决策记录 8 与 [版式实现](版式实现.md)。

## 5. 验收标准

全部可测量、可复现，不接受「看起来差不多」。

### 5.1 自动检查

1. `typst compile` 零错误。字体缺失警告（`unknown font family: simsun` 等）**属预期**，来自回退链中本机没有的候选，不作为失败依据。
2. 版心实测 = 上 30 / 下 20 / 内 30 / 外 25 mm（用 PDF 内容包围盒测量）。
  > 修订：下边界改为 270.93mm（下边距 26.07mm），版心 155 × 240.93mm。见 §2.1。
3. 行距实测 = **20.000 pt 基线距**，段内与跨段落一致（连续 10 行取平均）。**只看基线距，不看每页行数。**
4. 字号实测逐项匹配 §2.2 表格。
5. 页眉双横线：两条 0.5 pt、中心距 1 pt、**宽度 = 正文宽 155 mm（不外扩）**。
6. 页码：前置罗马 / 正文阿拉伯，各自从 1 起，页脚居中，字号 9 pt。

### 5.2 对照检查

7. 用本机 `xelatex` + `xdupgthesis.cls` 现场编译官方 PDF，渲染成 PNG，与本模板输出**逐页对照**。
  必须一致的结构页：封面、中文题名页、英文题名页、声明、中英文摘要、四个索引/对照表、目录、章首页、参考文献、致谢。
8. 已发现的 9 处冲突（§1 表格）逐条确认按裁定值实现。

### 5.3 功能矩阵

9. 四种组合全部能编译并输出正确页面：
  `academic` / `professional` × 正常 / 盲审。
10. 一份 ≥ 20 页的示例论文完整编译通过，包含：多级标题、图、表（三线表）、公式编号与引用、参考文献引用、附录。

## 7. 已确认的事实（供对照，避免重复调研）

- 官方 Word 最后修订：2025-01-08，44 页，含完整《撰写要求》。
- 学硕/专硕 Word 的页面与样式完全一致，差异仅在封面和题名页。
- 专硕的封面/题名页是 2022.11 单独修订的独立文件。
- 官方分发的 LaTeX 包（2024.04）落后于 Word，且不支持专业学位。
- 现行 xduts（CTAN）已修正页码字号、三级标题加粗，并支持企业导师。
- 官方 Word 页眉使用**双横线**（`w:val="double"`, 0.5pt, space=1pt），LaTeX 亦然。
- 官方目录条目顺序：摘要 → ABSTRACT → 插图索引 → 表格索引 → 符号对照表 → 缩略语对照表 → 正文。
- 前置部分各条目均占奇数页（V / VII / IX / XI），即 `openright`。

### 验证得出的事实

- **Typst 的 `pt` = Word 的「磅」= 1/72 英寸**（LaTeX 的 pt 是 1/72.27 英寸）。格式规格 §2 的「磅」值在 Typst 中**直接照抄数值**，不必换算。
- 固定值行距的实现：`text(top-edge: Δ, bottom-edge: "baseline")` + `par(leading: 20pt − Δ, spacing: 20pt − Δ)`，其中 `Δ = (20pt − 字号)/2 + 0.88 × 字号`。实测段内/跨段均为 20.000pt。
- `par(spacing)` 必须显式设成 `20pt − Δ`，否则 Typst 默认 `1.2em`（12pt 字号下 = 14.4pt）会破坏行网格。
- 页眉横线宽度 = 正文宽（三方一致），原 格式规格 「超出 4 磅」有误，已修正。
- 页眉帧顶 = 上边距 − `header-ascent`；页脚帧顶 = 版心下边界 + `footer-descent`。页眉/页脚内容须为零高度框 + `place`。
- 官方 LaTeX `templet.pdf` 关键实测：正文首行基线 99.53bp、页眉文字基线 73.18bp、双横线 78.36/79.36bp、页码基线 788.84bp、版心宽 439.37bp。
- 本模板同项实测：首行基线 99.60bp（+0.07）、页眉基线 70.68bp（−0.88mm）、双横线 27.21/27.56mm、版心宽 439.37bp（一致）。
- 修订后的页码基线：**279.50mm**（= 纸张高 − 页脚底 17.5mm，与已过检的真实论文实测一致；官方 2024.04 为 278.29mm）。旧值 281.73mm 偏高 2.23mm，已修。
- 官方 LaTeX 正文区顶边 = **85.04bp = 30.00mm**（由正文首行基线 99.53bp 反推），与 格式规格 §2.1 裁定一致；页眉横线在其上 6.68pt，页眉文字基线在其上 11.86pt。
- 官方 `templet.pdf` 全 44 页只嵌入三种正文字体：`SimSun`(75) / `NimbusRomNo9L`(77，TNR 开源等价物) / `SimHei`(17)。**楷体、仿宋 0 次出现**（Word `styles.xml`、`document.xml` 亦然）。→ 硕士论文只需 宋体/黑体/TNR。
- 官方章首页几何：章标题基线 125.44bp、正文首行 163.29bp；本模板复现 125.12 / 163.12bp（差 0.32 / 0.17bp）。章标题与正文共用 20pt 行盒（Δ=(20−16)/2+0.88×16=16.08pt）。
- Typst 的 `bottom-edge` **不接受长度参数**（实测被忽略，只有 `top-edge` 生效），无法把行盒直接做成 20pt。
- Typst 的 `block(above:)` 段前间距在页顶**会被折叠**；`v()` 强间距不会被折叠。
- 官方 LaTeX 的 `\baselineskip{20pt}`、`\textheight{24cm}`、`\headheight{31pt}`、`\headsep{0pt}`；Word `pgMar`: top=1701, bottom=1134, left/right=1418, header=1134, footer=992, gutter=284（twips）。
- Word `styles.xml` 正文样式：`sz=24`（小四）、`spacing line="400" lineRule="exact"`（固定 20 磅）；章标题 `sz=32` before=480 after=360；二级 `sz=30` before=360 after=240；三级 `sz=28` before=240 after=120 —— **与 格式规格 §2.2 逐条吻合**。
- Word 页眉样式 styleId=20：`pBdr bottom w:val="double" w:sz="4" w:space="1"`、`sz=21`（五号）、居中。
