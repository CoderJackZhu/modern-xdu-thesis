# 配套材料规格

本文件是 `supporting/` 下开题报告、中期考核报告和通用课程实验报告的数值与结构依据。
这些表单与学位论文正文是两类文档，**不得把 `docs/格式规格.md` 的论文版心套用到行政表上**。

## 一、覆盖范围

| 入口 | 覆盖对象 | 依据 |
|---|---|---|
| `proposal-documentclass` | 学术硕士、专业硕士、学术博士、专业博士开题报告 | 研究生院原始 Word 表 |
| `interim-documentclass` | 上述四类研究生的中期考核报告 | 研究生院原始 Word 表 |
| `bachelor-proposal-documentclass` | 本科毕业设计（论文）开题报告 | 本科生院《毕业设计表格-全套》第 5 号表 |
| `bachelor-interim-documentclass` | 本科毕业设计（论文）中期报告 | 本科生院《毕业设计表格-全套》第 6 号表 |
| `course-report-documentclass` | 通用课程实验报告 | 仅提供非官方骨架，不声称全校统一 |

科研实验记录本没有检索到全校统一的现行版式，因此不提供“官方模板”入口。学院或导师有要求时，
应使用其原始表格。

## 二、研究生开题与中期表

### 2.1 版式

研究生院 Word 表的填写说明明确规定：正文宋体、小四（12pt）、固定行距 20 磅。原始表单还写明
使用 A3 纸张正反套印；本模板输出单页 A4，供打印时按学院要求套印或提交电子版。在线系统最终
生成并带有系统条码、审批字段的表格仍以系统导出件为准，不能拿本模板替代系统中的流程表。

从原始 Word 文本结构提取的数值：

| 项 | 数值 |
|---|---|
| 正文 | 宋体 12pt |
| 行距 | 固定 20pt |
| 页边距 | 上、下、左、右各 25.4mm（原始 `pgMar=1440` twips） |
| 学校名称 | 16pt 粗体 |
| 表名 | 18pt 粗体 |
| 封面字段 | 14～16pt，按原表留白 |
| 页眉、页脚 | 无 |
| 框线 | 0.5pt 实线 |

### 2.2 字段差异

| 对象 | 学科字段 | 导师字段 |
|---|---|---|
| 学术硕士 | 一级学科、二级学科 | 指导教师 |
| 专业硕士 | 学位类别、领域 | 校内导师、校外导师 |
| 学术博士 | 一级学科、二级学科 | 指导教师 |
| 专业博士 | 学位类别、领域（方向） | 指导教师；意见区保留校内、校外导师双签 |

专业硕士开题报告的“论文概况”还包含实习单位名称、实习岗位、实习实践模式、计划实习时间、
论文类型与选题来源。专业博士、学术硕士、学术博士不强行添加这些字段。
专业博士封面与硕士专业学位的字段并不相同：原表封面只列“指导教师”，但专业博士的指导教师
意见页仍分别保留“校内导师签名”和“校外导师签名”两栏。

### 2.3 章节与顺序

硕士研究生开题报告顺序：

1. 论文概况
2. 选题依据
3. 研究方案
4. 研究基础
5. 指导教师意见
6. 开题报告记录
7. 开题报告评语及结论

博士研究生开题报告将“开题报告记录”和“评语及结论”前移，指导教师意见放在最后：

1. 论文概况
2. 选题依据
3. 研究方案
4. 研究基础
5. 开题报告记录
6. 开题报告评语及结论
7. 指导教师意见

博士开题报告的研究方案比硕士多“论文的创新点”；评语表按学术/专业的专家评价指标分别生成。
专业博士的选题与方案评价使用工程领域表述，不复制学术博士的“学科前沿”措辞。

中期考核报告统一为：

1. 学位论文研究目标及研究内容
2. 目前已完成学位论文工作的内容
3. 与开题报告内容不相符的情况说明
4. 下一步工作计划及需要完成的研究内容和需要解决的关键技术
5. 已发表/拟发表的成果
6. 指导教师评价意见
7. 中期总结报告评语及结论

## 三、本科开题与中期表

### 3.1 本科开题报告

依据本科生院资料包第 5 号表。原表为需装订的独立表，封面之后直接进入表格，不再复制论文摘要、
目录或学位论文封面。

| 项 | 数值 |
|---|---|
| 页面 | A4 |
| 页边距 | 上下 25.4mm，左右 31.7mm（原始 `pgMar` 1440/1800 twips） |
| 表名 | 黑体 22pt |
| 学校名称 | 18pt |
| 封面字段 | 约 15pt |
| 正文 | 宋体 12pt，固定 20pt |
| 续页 | 允许，表格框随内容延续 |

字段为：论文名称及项目来源、研究目的和意义、国内外研究现状和发展趋势、主要研究内容、
要解决的问题及初步方案、主要阶段、进度和完成时间、前期准备工作、指导教师意见、学院审核意见。

### 3.2 本科中期报告

依据本科生院资料包第 6 号表。原表要求可续页、勿更改表格样式，并写明一式三份、A3 正反套印、
最终胶装入存档论文。

| 项 | 数值 |
|---|---|
| 页面 | A4 |
| 页边距 | 上下左右各 25.4mm |
| 标题 | 方正小标宋简体 22pt（本包用黑体回退，不内置商业字体） |
| 正文 | 宋体 12pt，固定 20pt |
| 封面字段 | 16pt |
| 页眉、页脚 | 无 |

章节为：题目及进度是否变化、已完成工作及结果、后期计划、困难与问题、如期完成可能性、
导师意见、检查组意见、承担毕业设计单位审核。最后一项必须保留盖章位置。

## 四、通用课程实验报告

课程实验报告没有校级统一格式。`course-report-documentclass` 只提供可修改的通用骨架：
课程/姓名/学号/单位/教师信息栏、实验目的、环境、原理、步骤、结果、分析与结论，以及提交前
自查提示。源码和示例都明确说明“教师有指定模板时以教师模板为准”，不得把该入口描述为官方模板。
