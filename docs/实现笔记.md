# 实现笔记

Typst 实现学位论文版式时踩过的坑与验证过的写法。**这些是本项目实际花时间换来的**，
实现新页面（尤其本科模块）前先读一遍，能省掉同样的调试。

机制的实测数据见 [版式实现](版式实现.md)，硬约束与裁定见 [格式规格](格式规格.md)。

## 行距：Typst 的 leading 不是基线距

`par(leading)` 是**行盒之间的空隙**，不是基线距。直接写 `leading: 20pt` 会得到
「行盒高 + 20pt」，必然偏大。正确做法是把行盒拆成两段：

```typst
// Δ = 汉字字身框在固定行盒内居中时，基线距行盒顶的距离
#let 基线偏移(行盒, 字号) = (行盒 - 字号) / 2 + 0.88 * 字号
#let 上伸 = 基线偏移(20pt, 12pt)   // 14.56pt
#let 行隙 = 20pt - 上伸            //  5.44pt

#set text(top-edge: 上伸, bottom-edge: "baseline")
#set par(leading: 行隙, spacing: 行隙)   // spacing 必须显式设！
```

要点：

- 这样 `Δ + leading = 20pt` ⇒ 相邻基线距**精确** 20pt，段内与跨段落都成立。
- **`par(spacing)` 默认是 `1.2em`**，不显式设就会在段落边界破坏行网格。
- **只有 `top-edge` 接受长度**：`bottom-edge` 传长度会被**静默忽略**（实测
  `bottom-edge: 5.44pt` 与 `"baseline"` 结果完全相同）。所以行盒没法直接做成 20pt，
  只能靠「`top-edge` 长度 + `par(leading)` 补偿」。
- 本科用的是**1.5 倍行距**，不是固定磅值 —— 需要另一套算法，不要照搬上面这组常数。

## 页面级设置的位置（实测踩三次）

**`set page` / `counter(page).update` 写在 `show heading` 之类的 show 规则里不生效** ——
show 规则的作用域只覆盖它自己产出的内容，后续页拿不到，症状是**页眉页脚整段消失**
（编译不报错）。页面级设置必须写在**文档级**：mainmatter 顶层，或页面函数顶层。

**页码复位也不能写在 mainmatter 开头**：正文首章还要 `pagebreak(to: "odd")`，
会把复位点挤到多出来的空白页上，正文首页显示 2 而不是 1。

**`here().page()` 返回的是「当前流程位置本来会落在哪一页」**，不是「上一步的末页」。
实测目录占 p21 时，正文开头的 `here().page()` 返回 **22**。

## 空白填充页会丢掉页眉页码

前置部分每个小节都从奇数页起，中间空出的偶数页**继承文档级默认设置**，
而不是相邻小节在函数体内写的 `set page`（函数级只覆盖该函数产出的一页）。
若各页面函数各自 `set page(header: …, footer: …)`，这些填充页就是全空的 —— 与官方不符。

修法（不用改用户模板）：文档级默认页用 state 按分界切换，第一个带页码的页面置位：

```typst
#let 前置编号开始 = state("前置编号开始", false)
// 文档级：
    header: context if 前置编号开始.get() { 页眉(固定标题) },
    footer: context if 前置编号开始.get() { 默认页脚 },
// 第一个带页码的前置页开头：
  前置编号开始.update(true)
```

## `first-line-indent` 默认不缩进标题后的第一段

`set par(first-line-indent: 2em)` 只管段中的后续段落；标题/图/表之后的**第一段不缩进**
（`all` 参数默认 `false`）。中文论文里这会让每节首行都错，且**编译不报错**。

```typst
set par(first-line-indent: (amount: 2em, all: true))
```

## 段前间距在页顶被折叠

`block(above:)` / `heading` 的段前间距在**页顶会被折叠**，而 Word/LaTeX 的「段前 24 磅」
在章节首页页顶**照常生效**。章标题总在新页起，所以用**显式 `v(24pt)`（强间距）**。

标题与正文**共用同一个固定行盒**（章标题 16pt 也用 20pt 行盒）才能对上官方输出。

## `place` 定位与对齐

- **`place(top + left, dx: X)` 的 X 相对内容区左边界**，不是页面原点。规格给的是页面绝对
  坐标时，需把容器整体左移内侧边距（`place(top + left, dx: -内侧, …)`）。
- **`place` + `align(center)` 不会居中**：`place` 给内容收缩宽度，`align` 没有参照。
  必须套 `box(width: 版心宽, align(center, …))`。
- 页眉/页脚必须是**零高度框**再用 `place` 摆放，否则基准漂移。帧顶规律：
  页眉帧顶 = 上边距 − `header-ascent`；页脚帧顶 = 版心下边界 + `footer-descent`。

## 目录与索引（Typst 0.15）

- **定制目录条目的入口是 `show outline.entry`**，`outline()` 本身没有 `entry` 参数。
  条目字段只有 `level` / `element` / `fill`，页码要从 `element` 取：
  `numbering(loc.page-numbering(), loc.page())`（`page-numbering()` 可能为 none，要兜底）。
- **点填充三个坑**：① 不要把 fill 包成 `box(width: 100%)`（会把页码挤出正文区）；
  ② 页码列必须给固定宽度；③ **`grid` 的行不受 `par(leading)` 控制**，要固定行距得显式
  `row-gutter: 行距 − 行盒高度`。
- 目录页自己的标题要 `outlined: false`，否则目录会把自己列进去。

## 编号类元素：手写编号 = 永远无法引用

在 show 规则里**手写编号文本**会导致正文无法 `@引用`（报
`cannot reference equation without numbering`）。必须用真 `numbering`，分章编号则在其中
用 `context` 读章号：

```typst
#let 公式编号(..n) = context {
  let 章 = 章号.get().first()
  text(font: ("Times New Roman",), "(" + str(章) + "-" + numbering("1", ..n) + ")")
}
set math.equation(numbering: 公式编号)
set figure(numbering: 图表编号)   // 图/表同理，否则索引里会变成「图 1」而非「图 1.1」
```

三个连带坑：

- **figure 计数器不会自动按章重置**：还要 `counter(figure.where(kind: image)).update(0)`。
- **编号函数里的计数器是在「当前排版位置」求值的**：在索引页里写
  `numbering(f.numbering, ..f.counter.at(loc))` 会在索引页求值（那时一章都没有）→ 得到
  「图 0.1」。索引必须自己按元素位置算。
- **计数器定义在哪个模块决定谁能用**：定义在 `layouts/` 内部时 `pages/` 拿不到，
  要上移到共享模块（本项目放在 `utils/counters.typ`）。

## 图注里的引用会打乱参考文献顺序

数值型参考文献按**首次出现位置**编号，而插图索引/表格索引在正文之前 → 图注里的
`#cite` 会先被编号，导致整份文献顺序错乱。

**修法（实测有效）**：索引渲染条目前隐藏引用 —— `context { show cite: it => none; … }`。
（先动手试，不要凭推理下结论：曾推断「元素仍在文档里所以无效」，实测证明有效。）

## 索引类页面的页码用印刷页号

前置罗马、正文阿拉伯 → **物理页号 ≠ 印刷页号**。要用
`counter(page).at(loc).first()`，不是 `location().page()`。

## 参考文献

- Typst **自带** `gb-7714-2005-numeric` / `gb-7714-2015-numeric` CSL 样式，无需外部依赖。
  **本项目统一采用 2015**（依据见 [本科规格](本科规格.md) §七）。
- `bibliography()` **只收录被 `cite` 引用过的条目** —— 只用装饰性的 `#引用(1)` 会让参考
  文献页变成空的。
- 路径必须写成**根相对**（前导 `/`，相对 `--root`）：`bibliography()` 由包内页面调用，
  相对路径按那个文件所在目录解析。
- 「等」/「et al.」：CSL 只支持整篇统一语言，不支持逐条。本项目用后处理（`utils/bilingual-bib.typ`）
  按条目语言切换。

## 字体

- **先查官方输出实际嵌入了哪些字体**（`page.get_fonts()`），不要按「规范里列了哪些」推测。
  实测官方硕士输出全篇只有 宋体 / 黑体 / Times New Roman 三种。
- 不内置字体文件：中文字体基本是商业字体，放进仓库有版权风险；内置开源替代品又会让 PDF
  嵌入「不是宋体」的字体名，而格式检测会看字体名。
- 回退链**必须显式列出所有候选**：只给两个都无中文的字体时，Typst 会落到系统兜底字体
  （macOS 上实测落到过手写体，看起来像排版崩坏）。
- `unknown font family: simsun` 之类的警告是**预期行为**（回退链里本机没有的候选）。

## 其他零碎

- **`#import` 列表不能跨行**：`#import "x": a, b,\n  c` 会把第二行当成新语句。多个页面文件
  批量建时每个文件都会犯一次，写完先跑一遍批量修正脚本。
- **Typst 默认 heading show rule 会按 `1.4em` 放大字号**，用 heading 承载页面大标题时
  要在局部压掉（`show heading: it => block(above: 0pt, below: 0pt, { set text(size: …); … })`）。
- **`set text(size:)` 是作用域内全局的**：先设 12pt 画正文、之后忘切回 14pt，标题会静默变小。
  样式切换写在绘制处，不要依赖远处的 set。
- **给装中文字的盒子写固定宽度会截断长标签**：汉字宽度 = 1em = 字号，要按
  `字号 × clusters().len()` 算。
- **`pagebreak(to: "odd")` 在空页上会白跳一页**，要加 `weak: true`。
- 单位：Typst 的 `pt` 与 Word 的「磅」同义（1/72 in）；LaTeX 的 pt 是 1/72.27 in，
  拿官方 LaTeX 对照时行距会差约 0.075bp/行，属正常。

## 验证方法（比写代码更重要）

- **编译通过 ≠ 输出正确。** 本项目的全部历史 bug 都是「零错误、无警告、输出错」。
- 用 **PDF 反向测量**：`fitz`（PyMuPDF）取每行 `origin[1]` = 基线 y，相邻差即基线距；
  `page.get_drawings()` 取横线的位置、宽度与**线型**（`dr["dashes"]` 为空即实线）；
  栅格化墨迹包围盒查是否越出页边距。
- **判定线型不能只看段数或缩略图**：官方输出常把一条实线切成上百个 1mm 小段，
  看着像虚线，实际相邻段首尾相接。要读 dash 模式。
- **验收脚本必须先拿官方输出自检**：期望值正确时官方自身位移应为 0.00。自检不过说明
  期望值或匹配逻辑写错了。
- **新增验收项必须做负向测试**：把 bug 造回去确认报红 —— 本项目出现过一次「假绿」
  （检查只扫了第 1 页，其余页出问题照样通过）。
- **并排对照图只能定性，数值才是判据**：把两份 PDF 并排渲染后靠肉眼或缩略图判断，能发现
  「这个位置少了个东西」，但会把页码读错、把 27 条文献数成 30 条、把等大的元素判成 1.3 倍。
  凡是能用数字表达的（页码序列、横线条数与坐标、元素包围盒、字号），一律用测量脚本核对；
  对照图只用来提示「往哪里看」。实测中「页码偏移 8 页」「校徽明显偏大」经测量均为误判，
  「少了校名与校徽」「横线条数不对」经测量属实。
- **对照基准优先用实物论文而不是官方模板**：本项目的本科版式以已过检论文的 PDF 为准
  （页边距、页眉、封面坐标都能直接测）。官方 .cls 与手册给规则，实物论文给数字。
- `fitz` 常只在系统 `python3` 里，测量脚本用 `terminal` 跑，不要在代码沙箱里 import。
