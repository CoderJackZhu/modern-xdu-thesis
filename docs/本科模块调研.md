# 本科模块调研

调研目标：评估给本模板加入本科毕业设计（论文）支持的可行性、所需材料、与硕士的差异，以及工作量。

结论先说：**可行，且材料已齐**。本科与硕士的版式差异比预想的大（不是加几页就行），
但所需的官方规范、官方 Word 模板、官方 LaTeX 实现、以及一份真实成品 PDF 都已到手。

---

## 二、本科与硕士的格式差异（官方原文 + 实测）

来源：手册「七、毕业设计（论文）的打印规格」；实测来自 `main.pdf`（本人本科论文）。

| 项 | 本科 | 硕士（本模板已实现） |
|---|---|---|
| **行距** | **1.5 倍**（文字与公式都是） | 固定 20 磅 |
| 页边距 | 上 3 / 下 2 / 内 3 / 外 2 cm | 上 3 / 下 2.607 / 内 3 / 外 2.5 cm |
| 装订线 | **1 cm** | 0.5 cm |
| 页眉 | 2 cm | 2 cm ✓ 同 |
| 页脚 | **1 cm** | 1.75 cm |
| 版心 | 150 × 247 mm（实测 150mm 已确认） | 155 × 240.93 mm |
| **页码位置** | **页眉行最外侧**（宋体小五） | 页面底端中部 |
| 页眉内容 | 左页 = 论文题目；右页 = 章次 + 章标题；宋体五号 | 奇 = 章名；偶 = 校名；五号 |
| 页眉线 | **单线 0.75 磅** | **双横线 0.5 磅** |
| 章标题 | 黑体三号居中 ✓ | 黑体三号居中 ✓ 同 |
| 「小结」等 | 宋体四号居中 | — |
| 附录编号 | 附录 A/B/C，黑体三号；图表式与正文分开编（图 A1、表 B2、式(C-3)） | 附录页已实现，编号规则待对照 |
| 页码体系 | 「全文以右页为单页页码」，页码数据用对称页边距 | 前置罗马 / 正文阿拉伯，各自从 1 起 |
| 装订顺序 | **15 项**（含任务书、诚信书、成绩表、查重报告等表单） | 前置 6 页 + 索引 5 页 + 正文 + 后置 4 部分 |

**实测印证**：本人论文正文左边界 40.00mm（= 内 3cm + 装订线 1cm ✓ 与类文件一致），
版心宽 150mm ✓（= 210 − 内 3cm − 外 2cm − 装订线 1cm，与类文件的 geometry 一致）；
相邻基线差稳定在 **8.25mm ≈ 23.4pt**，与手册写的「行间距 1.5 倍」吻合
（按 1.5 倍反推基线约 15.6pt，与 ctexbook 12pt 档的默认基线同量级）。
官方文字与实测数据互相印证。

## 四、技术方案

本科与硕士的差异落在版式核心（版心、行距机制、页眉页脚位置），因此**不是「加一个页面模块」，
而是新增一套配置档（profile）**：

```
documentclass(
  level: "master" | "bachelor",        ← 新增
  degree: "academic" | "professional", ← 仅硕士有效
  ...
)
```

可复用的部分：

- 固定行距的实现思路（本科改 1.5 倍——机制同源，参数不同）
- 页眉/页脚的零高度框定位写法（本科页码挪到页眉行最外侧）
- 摘要、索引类、参考文献、致谢、作者简介诸页的**结构与排版代码**（数值换一套）
- 章节、图表公式的分章编号逻辑
- 全部验收工具（`dev/check-all.sh` 及各 `verify-*.py`）——只需再挂一套本科期望值

需要新做的部分：

1. 本科的封面、诚信书页面（与硕士封面不同，且学院间可能有差异——手册未给封面图样）
2. 页面几何：150 × 247mm、装订线 1cm、页脚 1cm
3. **行距机制改为 1.5 倍**（与固定 20 磅是两套算法）
4. **页码移到页眉行最外侧**（页脚位置随之清空）
5. 页眉：左页题目 / 右页章次+章标题，**单线 0.75 磅**
6. 附录编号（附录 A、图 A1、表 B2、式(C-3)）
7. 本科的验收期望值表（对照官方 Word 模板与本人 `main.pdf`）

## 五、需要你决定的范围问题

> **已定（用户裁定）**：独立表单不做；本科并入同一个包；本科与硕士**不共用文件入口**。
> 规格细节已落成 [`docs/本科规格.md`](本科规格.md)，以该文件为准。

1. **表单部分**：装订顺序里的 15 项中，任务书、诚信书、中期检查表、成绩评定表、查重报告等
   属独立表单，通常由学院发放、单独填写。硕士那份的裁定是「表单类不做」——本科沿用同一裁定？
2. **参考文献样式**：手册给的是「版本. 出版地：出版者, 出版年. 参考的页码」这类示例，
   与硕士采用的标准是否同源需进一步核对（**已核实：官方本科类为 2015；硕士亦已于 2026-09 切至 2015**）。这决定参考文献页是否要另写一套。
3. **是否同一包**：并入 `modern-xdu-thesis`（一个包覆盖本硕）还是另开一个包。
   建议并入——包名本身不含「硕士」含义，且两套共用大量代码。

## 八、建议

**可以做，且应该做成与硕士同一套质量标准**（逐项对照官方输出 + 真实论文压测）。
推进顺序建议：

1. 先补上「六」里那 4 个待确认点（其中封面图样需要你提供）
2. 从手册与 `xduugthesis.cls` 提取完整数值表，落成 `docs/本科规格.md`
3. 实现本科配置档；复用现有页面骨架，改数值与页眉页脚
4. 用本人 55 页 `main.pdf` 做压测验收，流程与硕士的 `docs/压力测试报告.md` 相同

不建议的做法的：直接移植 Hubert 的模板（无许可）；或不做验收就发布（会稀释本仓库唯一的卖点）。
