# 配套材料导航

配套材料是学位论文之外的行政表或课程材料。**先确认学院当前要求，再选入口**；学院给出的 Word
原表优先于本包模板。

## 学院与版本差异

- 集成电路学部 2026 年研究生开题/中期通知已经使用“学位论文或实践成果”的表述，并要求系统申请、
  导师审核、纸质表评审意见、成员签字和扫描件上传。硕士按学部要求执行，博士要求学校统一；
  不能把该学部通知直接当成所有学院、所有年份的统一规则。
- 专业博士 2026.09 资料包与学术博士 2025.01 资料包的字段、封面和导师栏目不同。切换
  `degree` 后必须核对封面上的“学位类别/领域”以及校内、校外导师栏。
- 本科表格来自本科生院《毕业设计表格-全套》。不同学院可能另发任务书、周记、中期检查表或
  实验记录本要求；这些文件不替代本科生院第 5、6 号表。
- 学校研究生管理系统可能自动生成带条码、审批流转信息的最终表格。本包输出的是排版稿，
  不应声称等同于系统导出件。

## 科研实验记录本、周记等材料

本次没有把科研实验记录本做成官方模板：目前只找到学院层面的备案要求，没有找到全校统一、可
稳定引用的版式。若学院要求使用实验记录本，请采用学院或导师提供的本子/表格；本包不会用
课程实验报告冒充科研记录本。

本科周记、任务书、中期检查表、诚信声明、评阅意见书等行政材料同样以本科生院资料包为准。
本次只实现最常用、且能核对到具体字段的开题报告和中期报告，不批量复刻所有审批表。

## 使用顺序

1. 打开学院最新通知，确认是开题还是中期、学术还是专业、硕士还是博士。
2. 从学校/学院下载原始 Word 表，核对字段和本页代码是否一致。
3. 用本包入口排版正文，保留原表的章节、评价指标、签名和盖章区域。
4. 需要系统提交时，以系统导出件和学院签字盖章要求为准。
