### 2.1 前置页面分页与官方完全一致

| 页面 | 官方 | 本模板 |

| 封面 / 中文题名页 / 英文题名页 | p1 / p3 / p5 | p1 / p3 / p5 |
| 声明 / 摘要 / ABSTRACT | p7 / p9 / p11 | p7 / p9 / p11 |
| 插图索引 / 表格索引 | p13 / p15 | p13 / p15 |
| 符号对照表 / 缩略语对照表 | p17 / p19 | p17 / p19 |
| 目录 / 第一章 | p21 / p23 | p21 / p23 |

页码序列也逐页一致：`XIII`(p21) → `XIV`(p22 空白页) → `1`(p23) → `2`(p24 空白页) → `3`(p25)。

### 2.2 逐行对照的结论

用官方自己的正文文本造一份内容一致的示例论文（第一、二章，官方 p23–p32），再逐页对照。

**行距比值**：本模板 7.055–7.060mm，官方 7.030mm，比值 **1.00356–1.00427**（理论 1.00375）。
即双方都在**各自单位下精确等于 20 磅** —— 差的 0.4% 来自 `1 pt = 1/72.27 in`（LaTeX）与
`1 磅 = 1/72 in`（Word/Typst）的单位定义差异，不是版式错误。

**章标题基线**：Δ = **−0.11mm**（p23）、**−0.35mm**（p25）。

**章标题 → 正文首行**：Δ = **−1.98mm**（p23）、**−2.46mm**（p25）。这是引擎行盒模型差异，
格式规格 §1 已裁定按规范标称值实现，不做魔数补偿。

## 3. 已知局限（如实记录）

### 3.1 逐行 y 无法逐行比对

字体度量不同（官方 `SimSun` / `NimbusRomNo9L`，本模板 `Songti SC` / `Times New Roman`），
**换行点会漂移**：官方某行到「…不得抄袭和剽窃他人」结束，本模板能多塞一个「要」字。
所以同一页第 k 行的 y 天生对不上，**逐行比 y 没有意义**。
`dev/compare-lines.py` 因此只比与换行无关的三项（行距比值、章标题基线、章标题→正文首行）。

要真正做到逐行 y 一致，前提是两端用同一套字体度量（即使用官方 SimSun）。
这在版权上不可行（见 格式规格 §2.2），因此**这一项不可达**，不是待办。

### 3.2 内容流决定的项只校字号与 x

节 / 小节标题、图表题注的 y 由前面的内容决定，`dev/verify-body.py` 只校**字号与 x**，不校 y。
第 2.2 节的逐行对照是对这一局限的补充手段，但它同样受 3.1 约束。

### 3.3 参考文献条目缩进

`.bib` 模式走 Typst 内置 `gb-7714-2015-numeric`，条目为**悬挂缩进**；
官方是「编号首行缩进 1.85mm、续行顶格」。字号（10.50pt）、行距（20.00pt）、
首条基线（60.02mm）、条目文本格式四项均与官方一致，**仅缩进方式不同**。

手工条目模式（`entries:`）的缩进与官方一致，但需要自行按 GB/T 7714 排版条目文本。

### 3.4 附录缺官方实测值

官方 `templet.pdf` 正文只有四章，**没有附录页**，因此附录页的坐标是按其它后置页推导的，
没有官方实测依据。

## 4. 盲审模式（格式规格 §2.6）

`blind: true` 的行为与验证：

| 项 | 处理 | 验证 |
|---|---|---|
| 封面 / 中文题名页 | 隐去作者姓名与导师姓名 | — |
| 英文题名页 | 隐去作者与导师行 | — |
| 致谢 | **删除文字内容，保留「致谢」标题** | 正文 0 次命中，标题存在 |
| 作者简介 | 字符串内容里的作者姓名替换为「（盲审隐去）」 | 张三 / 李四 / 王五 0 次 |
| 研究成果排序 | **保留**「第一作者 / 第一发明人」 | 标记存在 |

> 约定：内容写成**字符串**的，模板自动隐去姓名；写成 markdown 标记（`[...]`）的，
> 模板无法改写内容，需作者自行隐去。合作者署名不隐去（属正常引用信息）。

## 5. 修复记录：两个不报错的错误

编译通过、无任何警告，但输出是错的 —— 只能靠 PDF 反向测量发现。

| bug | 症状 | 根因 |
|---|---|---|
| 首行不缩进 | 每节第一段顶格 x=30.00（官方 38.47） | Typst `first-line-indent` 默认 `all: false`，**标题后的第一段不缩进** |
| 正文首页页码 = 2 | 官方 p23 是 `1`，本模板是 `2` | 页码复位落在目录后的空白页上；`set page` 写在 show 规则里则完全不生效 |

另修一个只在**独立使用**时暴露的 bug：`pagebreak(to: "odd")` 在「当前页本来就是空的奇数页」时
会白跳一页 —— 每章插了两次分页，前一次没有 `weak: true`。表现为：只含正文、没有前置部分的
文件里首个章被推到第 3 页。有前置部分时看不出来。

细节见 `docs/版式实现.md` .6。
