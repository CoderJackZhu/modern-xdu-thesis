# 本科规格

本科毕业设计（论文）的版式规格。**与硕士是两套独立规范**，本文件只写本科；硕士部分见
[格式规格](格式规格.md)。

## 权威来源

| 来源 | 用途 |
|---|---|
| 《毕业设计手册》2019（教务处，52 页） | **格式真值**（第七节「打印规格」给出全部页面与版面数据） |
| `xduugthesis.cls`（由 `xduts.dtx` 生成，1255 行） | 官方 LaTeX 实现，可提取全部版式参数与可选项 |
| 官方 Word 样例（教务处 `.doc`，2019，9 页） | 官方实物样例 |
| 本人本科论文 `main.pdf`（55 页） | 真实成品，用于验证与压测 |

前两项与 Word 样例存放于 `~/.hermes/assets/xdu-thesis-official/undergrad/`；
`xduugthesis.cls` 也可由本机已有的 `xduts.dtx` 重新生成。

## 一、页面与版面硬约束

手册第七节原文（本科）：

> 页面设置数据为：上 3 厘米、下 2 厘米、内侧 3 厘米、外侧 2 厘米；装订线 1 厘米；页眉 2 厘米；页脚 1 厘米。
> 版面设置数据为：文字的行间距— 1.5 倍；公式的行间距— 1.5 倍；字符间距— 标准；页码数据－对称页边距。

| 项 | 值 | 来源 |
|---|---|---|
| 纸张 / 装订 | A4，双面打印 | 手册 |
| 上 / 下边距 | 30 mm / 20 mm | 手册 |
| 内侧 / 外侧边距 | 30 mm / 20 mm | 手册 |
| 装订线 | **10 mm** | 手册 |
| 页眉距页顶 / 页脚距页底 | 20 mm / 10 mm | 手册 |
| **版心** | **150 × 247 mm** | 由上式推得；实测本人论文版心宽 150 mm ✓ |
| **行间距** | **1.5 倍**（文字与公式相同）；字符间距标准 | 手册；实测相邻基线差 8.25 mm ≈ 23.4 pt ✓ |
| 章节起始 | 主体部分另页右面开始 | 手册 |

> 与硕士的关键差别：硕士是**固定 20 磅**行距、装订线 0.5 cm、页脚 1.75 cm、版心 155 × 240.93 mm。
> 因此本科不能沿用硕士的固定行距实现，需另做「1.5 倍」机制。

## 二、页眉与页码

| 项 | 规格 | 来源 |
|---|---|---|
| 页眉字体 | 宋体五号（10.5 pt），居中 | 手册 |
| 页眉内容 | **左页（偶）= 论文题目**；**右页（奇）= 章次 + 章标题** | 手册；实测吻合 |
| 页眉底划线 | **单线 0.75 磅** | 手册 |
| **页码** | 宋体小五（9 pt），**排在页眉行的最外侧**，不加任何修饰 | 手册；实测吻合 |
| 页码体系 | 前置部分罗马数字、正文阿拉伯数字 | 实测（前置 i/iv，正文 1 起） |

实测（本人论文）：页眉与页码基线均在 **21.7 mm**；右页页码在 x = 189.1 mm（外侧），
左页在 x = 20.0 mm（外侧）。

> 与硕士的关键差别：硕士的页码在**页面底端中部**、页眉为**双横线 0.5 磅**、奇数页页眉为章名。
> 本科是「页眉行最外侧 + 单线 0.75 磅 + 左页放题目」，需重写页眉页脚组件。

## 三、字体与字号

| 元素 | 字体 / 字号 | 来源 |
|---|---|---|
| 正文 | 宋体小四（12 pt） | 实测本人论文；格式规格同族 |
| 章标题（含「摘要」「目录」「第一章」「附录」） | 黑体三号（16 pt），居中 | 手册 |
| 「小结」等节末标题 | 宋体四号（14 pt），居中 | 手册 |
| 页眉 / 页码 | 宋体五号（10.5 pt）/ 小五（9 pt） | 手册 |
| 关键词标签 | 加粗，小四 | 手册 |

## 四、标题层级与编号

手册示例与本人论文实测一致：

```
第一章 引言          ← 章：黑体三号居中
1.1 研究目的及意义    ← 节
1.2.1 基于手工特征的…  ← 小节（目录最多列到三级）
```

> 注：教务处 2019 年的 Word 样例正文用的是「一、引言」，与手册示例、官方 LaTeX 类、
> 以及本人论文（均已按官方类生成）不一致 —— **以「第一章」为准**，Word 样例视为旧版式。

## 五、各部分页面

按手册第三十三条，论文由「中英文摘要、目录、引言、正文、结论、参考文献、附录等」组成。

| 部分 | 要点 | 来源 |
|---|---|---|
| 封面 | 见下节（按本人论文实测） | 实测 |
| 中文摘要 | **不少于 300 字**；关键词列于摘要左下方 | 手册 |
| 英文摘要 | **不少于 300 个单词**，内容与中文一致 | 手册 |
| 目录 | 排在中英文摘要之后；列到三级 | 手册 + 实测 |
| 正文 | 含方案设计、解决的问题、测试实验结果、最后完成情况 | 手册 |
| 全文字数 | **不少于 15000 字**（外语专业可酌减，不少于 10000 单词） | 手册 |
| 参考文献 | 见下节 | — |
| 附录 | 编于正文后，**与正文连续编页码**，每一附录另页起；用大写正体 A/B/C 编号，黑体三号；附录中的图、表、式、文献与正文分开编号（图 A1、表 B2、式(C-3)、文献[D5]） | 手册 |

> 待核：手册列举的组成里未提「致谢」，但毕业设计通常包含。需按学院要求确认。

## 六、封面（按本人论文实测）

| 元素 | 实测规格 |
|---|---|
| 班级 / 学号 | 右上角，宋体 12 pt；两行（班级在上、学号在下），基线 28.2 / 36.5 mm |
| 「本科毕业设计论文」 | **42 pt**，居中，基线 84.2 mm |

> 手册未给封面图样，且各学院可能略有不同（Hubert 的模板即因此建议「用学校 Word 填写后合并」）。

## 七、参考文献

**本科采用 GB/T 7714-2015。** 依据是官方本科类的两处设置原文（`xduugthesis.cls` 第 1019–1026 行）：

```latex
% bibtex 路径
\RequirePackage[sort&compress,square,super,comma,numbers]{natbib}
\RequirePackage{gbt7714}
\bibliographystyle{gbt7714-numerical}
% biblatex 路径
\RequirePackage[style = gb7714-2015]{biblatex}
```

参考实现 Hubert 的 Typst 本科模板同样使用 `gb-7714-2015-numeric`。
手册给的示例写法偏旧（「版本. 出版地：出版者, 出版年. 参考的页码。」，未标类型标识），
与官方类不一致，以类实现为准。

### 附：硕士那一版的情况（同批核对）

| 官方材料 | 标准 |
|---|---|
| 硕士 Word 模板（2025.01）内《撰写要求》原文 | **2005**（原文写「著录格式遵循《文后参考文献著录规则》GB/T 7714-2005」） |
| 旧官方 LaTeX 类 `XDUthesis.cls`（2024.04，本模板所跟） | **2005**（`\bibliographystyle{gbt7714-2005}`，位于该类第 526 行） |
| **新版官方 LaTeX 类 `xdupgthesis.cls`** | **2015**（`\PassOptionsToPackage{style = gb7714-2015}{biblatex}`，第 1735 行；biblatex 为默认后端） |
| 一份已过检的 112 页硕士论文 | **2015** —— 其 `\documentclass{xdupgthesis}`，仓库内含 `main.bcf`（biblatex 构建痕迹） |

**结论（已裁定）**：硕士部分原采用 2005（与官方 Word 原文及旧官方类一致，合规），
**已于 2026-09 一并切换为 2015**，与本科统一。切换理由：
但学校较新的实现与近期的过检论文都走 **2015**。两版实际渲染差异极小（主要差
`@standard` 的 `[M]`/`[Z]`），因此 2005 未导致不合格，但跟随 2015 更稳妥。

## 八、装订与打印

手册第八节给出的装订顺序（15 项）：

```
(1) 封面      (2) 诚信书    (3) 任务书    (4) 工作计划   (5) 中期检查表
(6) 中期报告   (7) 指导教师成绩评定意见表   (8) 评阅人成绩评定意见表
(9) 成绩考核登记表   (10) 正文（含中英文摘要、目录、引言、结论、结束语、致谢、参考文献、附录等）
(11) 盲审意见书  (12) 修改说明  (13) 论文查重报告  (14) 外文资料翻译（可另装） (15) 指导情况登记表（可另装）
```

**范围裁定（用户已定）**：(2)–(9)、(11)–(15) 均为独立表单，由学院发放、单独填写，**本次不做**。
本模板只负责 **(1) 封面** 与 **(10) 正文**。

### 装订 / 打印相关的选项（已核对）

用户记忆中的「是否装订打印、页面整体左右移」经核对如下：

| 实现 | 相关开关 | 实际作用 |
|---|---|---|
| **本科** `xduugthesis.cls` | `bindingoffset = 1cm`（固定）+ `symmetric-margin`（默认 **false**） | 装订线恒为 1 cm；`symmetric-margin` 打开时外侧由 2 cm 改为 3 cm（对称） |
| 参考实现 | Hubert 模板的 `symmetrical-margins`（默认 false） | 同上 |
| **硕士** `XDUthesis.cls` | `pversion` / `eversion` | **注意：与装订无关** —— 经查全文件仅 2 处使用，只控制超链接是否着色与 PDF 书签设置，**不改页面几何** |

**建议**：装订线按手册固定 1 cm（即 `bindingoffset` 常开）；`symmetric-margin` **默认关闭**
（手册的页面设置写的是外侧 2 cm，打开会变成 3 cm 与之冲突）。

## 十、实现提示

- 本科不能沿用硕士的固定行距实现，需另做「1.5 倍」机制（`leading` 按 1.5 × 字面行高）。
- 页码位置从页脚改到页眉行最外侧，页脚留空（页脚距页底 1 cm 仅作定位参考）。
- 页眉需按奇偶切换「章标题」/「论文题目」，且**底划线为单线 0.75 磅**（硕士是双线 0.5 磅）。
- 验收：对照官方 Word 样例与本人 55 页 `main.pdf`，建立本科期望值表；
  流程与硕士的 `docs/验收报告.md`、`docs/压力测试报告.md` 相同。
- **不可移植 Hubert 的模板代码**：该项目无许可证（保留所有权利），只能看设计思路。
