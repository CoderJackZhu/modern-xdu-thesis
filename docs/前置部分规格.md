# 前置部分规格

> 所有数值来自官方原件，**不是推测**：
> - 位置 / 字号 / 字体 → 官方 `templet.pdf`（LaTeX 2024.04 编译产物）逐页测量
> - 段落间距 / 字体名 / 字段清单 → 官方 Word 2025.01 与专硕 2022.11 封面包的 `document.xml`
> - 格式裁定 → [docs/格式规格.md](../docs/格式规格.md) §1 / §2，**冲突时以 格式规格 为准**
>
> 坐标约定：A4 210 × 297 mm；`y` = 文字**基线**距页顶，`x` = 墨迹左右边界，单位 mm。
> 正文区 = 左右 30 ~ 185 mm。

---

## 0. 实现前提

前置页面**不使用正文的 20 磅行网格**，各页自带行距（见下）。但共用 `layouts/doc.typ` 的页面尺寸与页眉页脚机制。

前置部分统一：**每页从奇数页起**（`pagebreak(to: "odd")`），不足补空白页。页码罗马数字，从 I 起。

## 7. 验收标准

1. `typst compile` 零错误，`academic` / `professional` 两种模式都能输出 6 个页面。
2. 逐页测量并与本文档数值对照，**结构元素必须一致**：
  - 元素存在性、字体、字号、对齐方式 100% 匹配
  - 基线 y 偏差 ≤ 1.0mm（官方 Word 与 LaTeX 本身在页眉等处就差 0.9mm，故不要求更严）
3. 封面 / 中英题名页在两种学位下的字段清单正确（差集见 §1、§2.4）。
4. 前置部分每页从奇数页开始，页码罗马数字连续。
5. 与官方 `templet.pdf` 第 1 / 3 / 5 / 7 / 9 / 11 页渲染成 PNG 并排对照，人工确认结构一致。
6. 跑 `python3 dev/measure.py` 记录实测值，写进 报告。

## 8. 已知偏差（可接受，需在 报告中记录）

| 项 | 官方 | 本模板 | 原因 |
|---|---|---|---|
| 页码字号 | 10.5pt（五号） | 9pt（小五） | 格式规格 §1 裁定：官方 2024.04 过时，跟 Word 的小五 |
| 页眉位置 | 文字基线 25.82mm | 24.94mm | 格式规格 §2.1 页眉距页顶取 Word 的 20mm（差 0.88mm） |

## 9. 验收结果

**实现**：`layouts/doc.typ`（页面核心）+ 6 个 `pages/*.typ` + 重写的 `lib.typ`。
旧的南大页面已删除，`lib.typ` 对 页面用占位函数（调用时给出明确中文提示）。

**验收工具**：

```bash
python3 dev/measure.py <file.typ>       # 基线 / 字号 / 字体清单
python3 dev/verify-front.py <pdf> --degree professional  # 纵向：页 + 基线 y + 字号
python3 dev/verify-front-x.py <pdf> professional      # 横向：左边界 x
```

### 结果

| 检查 | 结果 |
|---|---|
| 编译（`template/thesis.typ` + 两个预览 + 3 个 文件） | 6/6 零错误 |
| 纵向验收 · 专业学位预览 | **0 / 34 不合格** |
| 纵向验收 · 学术学位预览 | **0 / 31 不合格** |
| 纵向验收 · `template/thesis.typ` | **0 / 34 不合格** |
| 横向验收 · 专业学位 | **0 / 12 不合格**（Δx 多在 0.00~1.10mm） |
| 横向验收 · 学术学位 | **0 / 14 不合格** |
| 工具自检 · 官方 `templet.pdf` 自身 | **0 / 31 不合格**（Δy 全为 0.00，证明期望值正确） |

**最大纵向偏差 1.27mm**，出现在封面题目第 2 行，原因是 §8 记录的 Word/LaTeX 行距冲突（按 Word 取 30pt）。其余全部 ≤ 0.9mm，多数为 0.00。

### 实现过程中修掉的问题

| 问题 | 根因 | 处理 |
|---|---|---|
| 6 个页面整体右移 30mm | `place(top+left, dx:)` 相对**内容区**（左边界 30mm），而源码把规格里的**页面绝对坐标**直接当成了 dx | `doc.typ` 新增 `页面坐标()`：把内容左移 `内侧`，容器原点与页面原点对齐，dx 可直接写绝对值 |
| 页眉落在 4.94mm（应 24.94mm） | 页面自己重写了一份页眉，不是零高度框，`header-ascent` 的定位规律失效 | 统一改用 `doc.typ` 的 `页眉()`（验证过的零高度框写法） |
| 封面长标签折行 | 标签盒子给了固定 `width: 32mm`，装不下 9 个汉字（44.5mm） | 去掉固定宽度，按墨迹宽自动展开 |
| 声明「使用授权说明」标题变成 12pt | 前一处 `set text(size: 12pt)` 之后没再切回 14pt | 标题样式改为在绘制处显式 `set text` |
| 题名页「密级」值缺字 | 值强制用了纯 `("Times New Roman",)`，中文无字形 | 值改走宋体字体链（西文 TNR + 中文 Songti SC） |
| 封面题目第 2 行多出 6.7pt 行距 | 行间同时有 `par(leading)` 和显式 `v()` | 改为逐行显式定位，行距固定 30pt |
| 摘要「关键词」位置错乱 | 正文用 `place` 脱离文档流，关键词的流式位置落回页顶 | 正文改走文档流，关键词自然跟随（`v(20pt)` = +40 磅） |

### 与官方渲染的视觉对照

`templet.pdf` 第 1/3/5/7/9/11 页与本模板对应页渲染成 PNG 并排比对，确认结构一致（元素、字体、字号、对齐、留白）。
