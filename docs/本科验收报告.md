# 本科模块验收报告

本科入口实现后的验收记录。版式期望值只来自 [本科规格](本科规格.md)，本报告记录测量方法与结果。

## 1. 基准材料

| 材料 | 用途 |
|---|---|
| 《毕业设计手册》2019（52 页） | A4、页边距、装订线、页眉页脚、1.5 倍行距、标题字号与附录编号的规则真值 |
| 教务处优秀毕业设计（论文）Word 样例（9 页） | 核对组成和旧版正文示例；其“一、引言”与手册、官方类和实物论文冲突，不作为标题编号基准 |
| `xduugthesis.cls` | 核对 30/20/30/20mm + 10mm 装订线、页眉内容、0.75pt 单线、标题间距和附录编号 |
| 一份已通过学校检查的 55 页本科毕业论文（未公开） | 坐标、分页和参考文献基准 |

当前机器没有 Word 或 LibreOffice，旧 `.doc` 通过 macOS `textutil` 只读抽取文本与样式表；不能把
Cocoa HTML Writer 的 CSS 当成 Word 页面坐标。可自动反向测量的版式基准采用同一官方本科类生成的
55 页 `main.pdf`。Word 样例中可核对的正文层级属于旧版，按 [本科规格](本科规格.md) §四的冲突裁定不采用。

## 3. 55 页压力测试

`dev/undergrad/port.py` 用 Pandoc 将真实本科论文转换为临时 Typst 输入，
`dev/undergrad/stress.typ` 通过包导出的 `bachelor` 模块排版。结果：

- 总页数：55 = 55；
- 五章印刷页起始：1 / 7 / 19 / 27 / 41，与源论文一致；
- 参考文献：27 = 27；
- 章物理页：9 / 15 / 27 / 35 / 49，全部为右页；
- PDF 版式检查：`不合格：0 / 27`。

Pandoc 会丢失少数复杂表格及其浮动高度。转换脚本在第三章、第五章前补回共 4 页，压力测试入口在
参考文献末补 1 页，使分页骨架仍可与源论文核对；这些补偿仅存在于 `dev/undergrad/`，不进入模板代码。
正文的 23.4pt 基线距、150mm 版心、页眉和章起始位置仍由 PDF 反向测量独立验证。

> **注意分页数值的效力**：上面「55 = 55」与章起始页一致，是在补页之后得到的结果 ——
> 它证明的是分页**骨架**可对齐，不等于模板自身逐页复现了源论文。Pandoc 丢内容是转换链路的
> 局限，补页是承认这一局限的权宜做法。真正独立于转换链路的证据是版式测量（§2）与
> 排版规则本身（行距、版心、页眉页码、封面坐标），以及中日韩字形等宽带来的换行稳定性。

## 4. 负向测试

`bash dev/test-undergrad-negative.sh` 在临时副本中分别造回四类错误：

1. 把正文行距从 23.4pt 改为 20pt；
2. 把页眉线从 0.75pt 改为 1.5pt；
3. 去掉目录里「只有编号标题才加章号」的判断，让附录/参考文献/致谢的目录条目带上章号；
4. 把封面填写横线改短（官方为 82.1~166.8mm，宽 84.7mm）。

四份错误 PDF 均被 `verify-undergrad.py` 判为不合格，证明新增检查不是假绿。

`bash dev/test-bachelor-cover-assets.sh` 另在包外项目中覆盖默认占位符、调用方 `path(...)`
素材、单次 `cover()` 覆盖和关闭封面四种场景；其负向自测故意只替换一个占位符，验收器必须报错。

## 6. 与实物论文逐项对照

除验收脚本外，另用**实物论文 PDF 本身**逐项核对模板产物（脚本测的是模板自带的示例，
本节测的是同一篇真实论文）。基线与脚本结论互相独立。

| 对照项 | 实物论文（LaTeX 产出） | 本模板重排 |
|---|---|---|
| 摘要 / ABSTRACT / 目录 | p3 / p5 / p7 | p3 / p5 / p7 |
| 第一章…第五章物理页 | 9 / 15 / 27 / 35 / 49 | 9 / 15 / 27 / 35 / 49 |
| 参考文献起始页 | p53 | p53 |
| 印刷页码序列 | i…vi，1…47 | i…vi，1…47 |
| 正文行距 | 8.25mm | 8.25mm |
| 文献条目 | [1]–[27] | [1]–[27]，内容一致 |

封面按实物论文测得的位置和尺寸逐条比对；官方标识本身不用于仓库内验收：

| 元素 | 实物论文（x / y，宽 × 高） | 本模板 |
|---|---|---|
| 校名书法字区域 | 77.7 / 49.4，64.4 × 12.0mm | 77.7 / 49.5，64.5 × 12.04mm；默认显示占位符 |
| 校徽区域 | 89.0 / 107.3，42.0 × 41.9mm | 89.0 / 107.2，42.1 × 42.1mm；默认显示占位符 |
| 填写横线 8 条 | 班级/学号 146.1~174.8；题目与字段 82.1~166.8 | 逐条相同 |

正文逐行 y 无法比对：字体度量不同导致换行点漂移，此约束不可达（见 [实现笔记](实现笔记.md)）。

## 7. 修正记录

### 7.1 目录里后置部分条目带上了章号（已修）

现象：目录显示「第二章 附录 A 补充实验」「第二章 致谢」「第二章 参考文献」，
而实物论文目录是干净的「附录 A 补充实验」「致谢」「参考文献」。

成因：`bachelor/pages.typ` 的目录 show 规则**无条件**给每个一级条目加「第X章」；
而 `页面标题()`（`bachelor/layout.typ:95`）已用 `numbering: none` 登记后置部分标题
（所以页面上是对的），目录却读 `counter(heading)` 硬加编号。

修复：目录条目先判 `it.element.numbering`，为 `none` 时不加任何编号。

### 7.2 封面标识区域与填写横线（已修）

现象：

- 官方封面「本科毕业设计论文」上方是**校名书法字**（64.5 × 12.0mm）、下方是**校徽**（42.1mm 见方）；
  二者在官方 PDF 里都是**图形**（无文字层）。模板原先只用一行 28pt 黑体文字代替校名、且无校徽。
- 官方填写横线共 **8 条**（班级/学号 2 条 + 题目 2 条 + 字段 4 条），模板只有 6 条（缺题目两行）。
- 班级/学号的**值**未居中于横线（模板中心 170.5mm，官方 160.4mm）。

修复：按实物论文测得的包围盒固定校名标准字与校徽区域，补齐 8 条横线，并让题目与各字段的值
在横线上居中。学校未提供可核实的标识再分发条款，因此当前实现不内置图片：用户可通过
`cover-wordmark` / `cover-emblem` 传入调用方构造的路径，未传入时同一区域显示占位框（见 §6）。

## 8. 规格文档的更正

`docs/本科规格.md` 第六节封面表原先漏了「校名书法字」「校徽」两行与填写横线条数，
规格中原先缺少这两项依据，是这两处偏差的根源。**已在规格中补齐**：8 条横线的精确坐标、
校名与校徽的图片形式与位置，以及不内置标识、由用户传入路径和无素材时显示占位框的规则。

## 9. 新增的回归验收项

`dev/verify-undergrad.py` 增加默认封面检查（仅在非 `--reference`/`--stress` 模式下）：

- `目录后置条目无章号`
- `封面填写横线 8 条`
- `封面含校名标准字占位提示` / `封面含校徽占位提示`
- `封面校名标准字占位框` / `封面校徽占位框`

包外路径、逐次覆盖、关闭封面和素材像素区域由 `dev/test-bachelor-cover-assets.sh` 独立验证；
对应的负向用例见 §4。

## 10. 使用注意

- **压测素材路径**：本科压力测试需要一份已过检的本科论文仓库，路径由 `UNDERGRAD_STRESS_SRC`
  指定（写进 `dev/local-paths.sh`，已 gitignore）；未指定时该节检查**跳过而非报错**，
  注意输出中的「跳过」字样。
- **封面官方标识**：仓库不分发校名标准字与校徽；使用者从学校官方附件取得后自行传入，
  处置方式见 §8 与 §13。

## 12. 本科与硕士页面实现的收敛评估

`bachelor/`（`layout.typ` + `mainmatter.typ` + `pages.typ`，约 420 行）与硕士的
`layouts/` + `pages/`（约 950 行）是否应该抽公共层，逐项核对后结论如下。

**已经共享的部分**：

- `utils/style.typ`（字体回退链、字号表）——两侧字体/字号定义**完全一致**，一直共用。
- `utils/bilingual-bib.typ`（双语参考文献「等/et al.」后处理）——两侧共用同一实现。
- `utils/counters.typ` 的 `索引题注`——两侧的索引/正文双题注机制共用。

**去重后共享的纯数据**（两侧取值逐字相同，抽取不改变任何一侧的输出）：

- `汉字序`（“一”至“二十”的中文数字表，供「第X章」标题用）：硕士 `layouts/mainmatter.typ`
  与本科 `bachelor/layout.typ` 各自内联了一份完全相同的 20 项数组；硕士那份**从未被
  引用**（硕士的章号是作者手写在标题正文里的中文，模板不生成，见 `mainmatter.typ`
  文件头注释），纯粹是历史遗留的死代码。现统一移到 `utils/counters.typ`，硕士侧不再
  定义（原本也不用），本科侧改为从共享模块导入。`bash dev/check-all.sh` 复跑 20/20，
  硕士 13 项与本科 7 项均未变化，证明这次去重零副作用。

**评估后判断不收敛的部分**（理由逐项列出，均是算法或数值本身不同，不是「凑巧写了两遍」）：

| 差异点 | 硕士 | 本科 | 为什么不能共用 |
|---|---|---|---|
| 行距算法 | 固定 20pt 行盒，`基线偏移(行盒, 字号) = (行盒-字号)/2 + 0.88×字号` | 1.5 倍行距，`基线偏移(字号) = 0.88×字号`（无行盒参数） | 函数签名和公式都不同——是两种排版模型（定长 vs 比例），不是同一逻辑的重复实现，强行合并需要引入模式分支，反而更难验证 |
| 页面几何 | 155×240.93mm 版心，装订线 0.5cm，页脚 1.75cm | 150×247mm 版心，装订线 1cm，页脚 1cm | 纯数值差异，来自两份不同的官方规格；已通过 PDF 反测各自锁定，抽公共函数只是多一层参数传递，不减少需要维护的数值个数 |
| 页眉/页码 | 页码在页脚居中；页眉双线 0.5pt，奇偶内容=章名/校名 | 页码在页眉行最外侧；页眉单线 0.75pt，奇偶内容=章标题/论文题目（与硕士相反） | 位置、线型、内容语义均不同，共用的唯一收益是「都要判断奇偶页」这一行 `calc.odd/even`，收益低于引入共享接口的复杂度 |
| 附录编号 | 单篇附录，无跨类型编号 | A/B/C 多附录，图 A1/表 B2/式(C-3) 独立编号体系 | 硕士侧功能子集为空，没有对称的抽象点 |
| 封面 | 硕士封面固定不可关闭 | 本科封面可开关（`cover-enabled`），标识素材可由用户传入 | 组件形状与素材接口不同，非同构 |

**结论**：不做进一步收敛。已共享的三处（字体字号、双语文献、索引题注）覆盖了两侧真正
同构的部分；新去重的 `汉字序` 是唯一发现的「数值完全相同却抄了两遍」的代码；其余差异
是规格本身不同导致的，参数化抽象只会增加一层间接、不减少需要独立维护和验证的数值，与
`docs/本科规格.md`/`docs/格式规格.md` 中「数值互不套用」的裁定原则一致，且违背改动风险
应与收益匹配的原则。若未来硕士版式发生变化，`bachelor/` 需要作者显式检查是否同步适用——
这是「不共用入口」的既定代价，不建议为了消除这个代价而引入运行时耦合。

## 13. 封面官方标识处置（复核）

学校官方校名标准字与校徽的再分发条款不可得，因此仓库和软件包不保存、不分发这两项素材：

- `cover-wordmark` 与 `cover-emblem` 默认为 `none`；用户从学校官方附件取得文件后，以调用方
  构造的 `path(...)` 传入，包代码只控制固定位置、宽高与 `fit: "contain"`。
- 未传入时，以 Typst 原生浅灰色矩形显示明确的用户提供提示；占位框保持 64.5 × 12.04mm
  与 42.1 × 42.1mm 的既定几何，不伪造学校标识。
- `cover-enabled: false` 会跳过整个封面组件，既不读取用户路径，也不显示占位符；可用于插入
  学院提供的官方封面。
