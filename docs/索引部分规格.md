# 索引部分规格

> 数值来自官方 `templet.pdf` 第 13 / 15 / 17 / 19 / 21 / 22 页实测（LaTeX 2024.04）。
> 坐标约定：A4 210 × 297 mm；`y` = 文字**基线**距页顶，`x` = 墨迹左边界，单位 mm。
> 前置部分均为奇数页，首页从 **p13** 起（p13 插图索引 / p15 表格索引 / p17 符号对照表 / p19 缩略语对照表 / p21 目录）。

## 1. 插图索引（`pages/list-of-figures.typ`）

**条目格式**：`图 <章-序> <图题> ……………… <页码>`

| 元素 | 字体 | 字号 | 基线 y | 位置 |
|---|---|---|---|---|
| `图` | 宋体 | 12pt | 61.12 | x = 30.00 |
| 编号 `4.1` | Times New Roman | 12pt | 61.12 | x = 36.35 |
| 图题 | 宋体 | 12pt | 61.12 | x = 46.94 |
| 点填充 | TNR | 12pt | 61.12 | 66.00 → 175.05 |
| 页码 | TNR | 12pt | 61.12 | **右对齐到 185.00** |

- 首个条目基线 **61.12mm**，后续条目行距 **固定 20 磅**（7.06mm）。
- 数据来源：`query(figure.where(kind: image))`（验证可用）；编号为**分章编号**（格式规格 §2.5）。

## 5. 目录（`pages/outline.typ`）

**条目格式**：`<编号> <标题> ……………… <页码>`

| 层级 | 编号字体 | 标题字体 | 编号 x | 标题 x |
|---|---|---|---|---|
| 一级（章 / 前置部分） | — | **黑体** | — | **30.00** |
| 二级（节） | TNR | 宋体 | 36.22 | 45.76 |
| 三级（小节） | TNR | 宋体 | 45.76 | 56.35 |

- 首个条目基线 **57.76mm**，条目行距 **固定 20 磅**（实测 7.10mm）。
- 点填充 + **页码右对齐到 185.00**。
- **最多三级**（格式规格 §2.4）；四级标题用「（1）」形式且不进目录。
- 一级条目含 `ABSTRACT` 等纯西文时为 TNR（格式规格 §2.2：一级条目西文 TNR、中文黑体）。
- 收录范围 = **前置部分全部条目 + 正文章节 + 参考文献 / 致谢 / 作者简介**，按文档顺序。

### 实现机制（已探针验证）

- 用 Typst 原生 `outline(depth: 3)`，前置部分各页标题做成 `heading(level: 1, outlined: true)`。
 探针确认：**`place` 定位的 heading 也能被 `outline()` 收录**，且按文档顺序排列。
- 自定义 `entry` 按层级套字体与缩进；编号用**定宽盒**保证标题左边界对齐。
- 官方对 4 字符编号（如 `2.10`）的标题会左移约 2mm（LaTeX 目录样式所致），本模板用定宽盒统一对齐，属可接受偏差。

## 6. 已知偏差

| 项 | 官方 | 本模板 | 原因 |
|---|---|---|---|
| 目录页标题基线 | 44.33mm | 44.25mm | 与其余四页统一（差 0.08mm） |
| 目录 4 字符编号的标题位置 | 会左移 ~2mm | 定宽盒统一对齐 | 官方 LaTeX 目录样式的副作用 |
| 页码字号 | 10.5pt（五号） | 9pt（小五） | 格式规格 §1 裁定（同） |

**插图/表格索引与目录的条目内容依赖 **：只实现结构，正文与图表补齐后自动填充。

## 7. 验收结果

**实现**：5 个页面文件 + `layouts/doc.typ` 新增的共用组件（`页面大标题` / `点填充` / `索引条目`）。

**验收工具**：`python3 dev/verify-index.py <pdf>`
先按「16pt 标题」定位页面再逐项比对，**不依赖页面顺序**；同时比 y（基线）与 x（左边界）。

### 结果

| 检查 | 结果 |
|---|---|
| 编译（主模板 + 4 个预览 + 3 个 文件） | **7/7 零错误** |
| 验收 · 含正文标题的专测 PDF | **0 / 23 不合格** |
| 验收 · `template/thesis.typ`（无正文/图表，条目类自动跳过） | **0 / 18 不合格** |

### 实现过程中修掉的问题

| 问题 | 根因 | 处理 |
|---|---|---|
| 页面大标题左对齐而不是居中 | `place` 里直接 `align(center)` 没有确定宽度 | 套 `box(width: 155mm, …)` |
| 标题字号被放大成 22.4pt | Typst 默认 heading show rule 会按 1.4em 缩放 | 局部 `show heading` 同时压掉缩放与上下间距 |
| 「目录」把自己也列进目录 | 目录页标题也登记为 outline 条目 | 目录页标题用 `outlined: false` |
| 索引条目的页码被点填充挤没 | 页序列用 `auto`，贪婪的 `repeat` 撑满整行 | 页码列改**固定 12mm** 宽 |
| 点填充一行撑到 185mm | `box(width: 100%, repeat(…))` 按父容器 100% 撑开 | 直接把 `repeat` 元素交给 1fr 列 |
| 符号表第 2 列跑到 128.36mm | 把「页面绝对 x 之差」当成了「内容区宽度」（多算 30mm） | 列宽改为 `98.36 − 34.13 = 64.23mm` |
| 表格数据行行距只有 14.56pt | grid 行不受 `par(leading)` 控制 | 显式 `row-gutter: 20pt − 正文Δ` |
| 索引条目文字间距随机 | markup 换行会额外产生空格，与 `h()` 叠加 | 改用 `+` 显式拼接 |
| `outline` 不接受 `entry` 参数 | Typst 0.15 的定制入口是 `show outline.entry` | 改 show rule；页码用 `numbering(loc.page-numbering(), loc.page())` |

### 已知偏差（可接受）

| 项 | 官方 | 本模板 | 原因 |
|---|---|---|---|
| 目录页标题基线 | 44.33mm | 44.25mm | 与其余四页统一（差 0.08mm） |
| 索引条目编号格式 | 分章 `4.1` | 全局 `1` | Typst 默认 figure 编号；**定义分章编号后自动修正**（格式规格 §2.5） |
| 目录宽编号的标题位置 | 官方自身会左右浮动 ~2mm | 按层级整体缩进 | `outline.entry` 只暴露 content 类型的 `body`，无法可靠切出编号；用 `numbering(element.numbering, …)` + 定宽编号列可精确对齐 |
| 符号表/缩略语表长条目换行 | 官方样例用 XXX 占位，无从对照 | 长文本会换行并撑高该行 | 列宽已按官方值固定；换行是正常行为 |
