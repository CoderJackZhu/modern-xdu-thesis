# 博士学位论文规格

核对日期：2026-10-29。本文件是博士差异数值的唯一来源；没有列出的主体样式继承
[格式规格](格式规格.md)，不得套用本科数值。

## 来源与裁定

- 学术博士：[研究生院资料页](https://gr.xidian.edu.cn/info/1047/7160.htm)，附件 2025.01。
- 专业博士：[研究生院资料页](https://gr.xidian.edu.cn/info/1047/7803.htm)，附件 2026.09，
  内含 2026.5 专用封面和中英文题名页、使用说明。
- 资料包含旧版 `XDUthesis.cls` 及通用硕士 `templet.pdf`，另推荐 xduts。
  xduts 的 `xdupgthesis.cls` 支持硕/博与学术/专业组合；它是参考实现，不是独立博士金标准。
- 专业博士必须使用专用封面、题名页。正文、声明、摘要、索引、后置部分沿用研究生论文要求。
- xduts 的博士英文 `Doctor of Philosophy` 不能用于所有博士：工程博士 Word 明写
  `Doctor of Engineering`。读取 `degree-name-en`；学术默认前者，专业默认后者。
  专业博士 `in ...` 填类别英文 `category-en`，学术填 `discipline-en`。
- 无企业导师时移除该栏目；盲审保留栏目位置但隐去身份、PDF 作者元数据。

## Word 锚点与基线重建

以下坐标单位均为 Word 磅（1/72 英寸），来自原始 DOCX 的 VML 文本框
`margin-left / margin-top / width`。坐标相对正文区（左、顶均按 30mm）。
使用 DrawingML 与 VML 中的一份，避免重复计数。

| 区域 | 学术 x / y / 宽 | 专业 x / y / 宽 |
|---|---|---|
| 封面题目 | 14.2 / 439.45 / 425.2 | 14.2 / 411.1 / 425.2 |
| 封面字段 | 99.25 / 567 / 269.3 | 99.25 / 524.5 / 255.1 |
| 中文校名 | 0 / 113.4 / 439.35 | 0.5 / 113.75 / 439.35 |
| 中文题目 | 0 / 311.85 / 439.35 | 0.5 / 311.5 / 439.35 |
| 中文字段 | 127.6 / 453.6 / 297.65 | 127.6 / 453.35 / 255.75 |
| 左上信息 | 5.65 / 8.5 / 127.55 | 5.9 / 8.45 / 127.9 |
| 右上信息 | 309 / 8.5 / 127.55 | 309 / 8.45 / 127.85 |
| 英文题目 | 0 / 0 / 439.35 | 0.5 / -0.15 / 439.35 |
| 英文中部 | 0 / 170.1 / 439.35 | 0.5 / 169.65 / 439.35 |
| 英文 By 区 | 0 / 530.25 / 439.35 | -0.45 / 510.3 / 439.35 |
| 英文导师 / 职称 | By 区第三行合并 | 47.1 / 570.2 / 191.6；230.85 / 571.15 / 219.1 |

字号及段落值取原始 Word：题目 22pt 加粗，校名 26pt 黑体加粗，
“博士学位论文”24pt 宋体加粗；封面/中文字段 14pt，标签加粗；
顶部信息统一 10.5pt（忽略样例个别值 11/12pt 的不一致）；英文正文 16pt TNR。
行距除中文字段为 32pt、顶部信息为 16.35pt 外均 30pt。
校名之后有两空行，故论文类型基线比校名行框顶下移 90pt。
题目最多三行，要求作者显式分行；超宽时明确报错，避免覆盖其他区域。

原始锚点是框顶而非文字基线。实现采用已验证的研究生行盒规则：
`基线 = 30mm + 框顶 + 行号 × 行距 + (行距 - 字号)/2 + 0.88 × 字号`。
英文导师与职称分别沿用两个框的顶边（保留原文 0.95pt 差异）。
专业日期在 By 后第 4 行（即 +120pt）；学术日期在唯一导师后下一行。
封面填空线沿用 Word 单下划线的连续实线，绘于重建基线下 1.5pt，
横向位于标签之后到文本框右端；这部分是字体无关的实现裁定，尚无原生 Word 墨迹宽度验收。
顶部填空线按 Word 导出可辨的线段：左 x=144.5 至197.05pt、右 x=431.9 至512.4pt；
顶边信息为自动倍距，重建为 16.35pt，线在基线下1.5pt。

## 字段及内容

- 学术封面：作者、指导教师、申请学位类别；中文页：作者、一级学科、二级学科、
  学位类别、指导教师、学院、提交日期。
- 专业封面：作者、学校导师、企业导师、申请学位类别；中文页：作者、领域、
  学位类别、学校导师、企业导师、学院、提交日期。无企业导师则移除对应行，后续上移一行。
- 页眉固定名称：“西安电子科技大学博士学位论文”，章页与后置页的奇偶规则沿用硕士。
- 作者简介默认用“攻读博士学位期间的研究成果”。
- 中文摘要约1500字，正文一般不少于5万字，参考文献一般不少于80篇、近5年不少于20篇。
  这些是写作要求，不在模板里自动补字数或文献。

## 验收边界

`dev/verify-doctor.py` 反向测量两个学位类型的三张前置页，检查文字、字号、基线、
横向边界、实线，以及正文/后置页/填充页的博士页眉、20pt行距、页码和盲审元数据。
`dev/test-doctor.py` 通过故意改坏字号、位置、学位名、页眉、匿名等验证验收尺会失败。
`dev/verify-doctor-word.py` 将原始 DOCX 的文本框与实现中的锚点逐项核对；
给总验收设置 `DOCTOR_ACADEMIC_WORD`、`DOCTOR_PROFESSIONAL_WORD` 后会运行该自检及负向测试，
缺失时明确跳过。官方文件仍由使用者自备，不分发到仓库。

专业 Word 曾用 LibreOffice 导出，但中文字体被替换、墨迹宽度失真，不能把其包围盒当作
原生 Word 的基线。该导出仅作辅助观察；本实现对齐 XML 锚点并重建基线，
未声称逐像素复现原生 Word，也未获学校实际格式检测验收。
硕士 `templet.pdf` 只用于共用正文回归，不能证明博士前置页通过。
